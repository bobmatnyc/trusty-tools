# Line: SRC_REL[<TAB>DEST_REL]. SRC_REL is relative to --source (the Architect
# checkout), DEST_REL to --staging, laid out like python/trusty-architect/.
# DEST_REL defaults to SRC_REL. A SRC_REL ending in /** copies every file under
# that directory, and DEST_REL is then a directory. Lines starting with # and
# blank lines are skipped.
#
# Starter set: exactly what python/trusty-architect/ ships today. Each later
# export PR adds the rows it ships, reviewed with its content. A skill shipped
# in trusty-tools form (its frontmatter and wording rewritten by hand, #10161)
# is never overwritten by a later export: re-export it to a scratch staging
# directory, diff it against the shipped copy and run the leak pass, then
# hand-merge the delta. Instance paths
# (local/, owner/, records/, inbox/, docs/briefs/, .env*, .mcp.json, ...) are
# refused by the tool even when listed here. Never add an instance-* skill or
# any path that names an account, host or person.
