# architect_leak_patterns.txt — the ONE pattern table for the Architect leak gate (#9996).
#
# Read by scripts/check_architect_subproject.sh (grep -E) and by
# `scripts/check_content.py leaks` (Python re). Edit here, never in either tool.
# Both tools never print a credential: an EMAIL hit shows as ***@domain and a
# line that also matches SECRET prints no matched text. Both scan binary and
# non-UTF-8 files as bytes. Both tools fail closed on a missing file, a malformed or empty line, or a
# pattern their engine rejects.
#
# Line format, four TAB-separated fields (the last is optional):
#   CLASS <TAB> FLAGS <TAB> MATCH <TAB> ALLOW
#   FLAGS  "i" = case-insensitive, "-" = case-sensitive.
#   MATCH  an extended regex. Keep it to the subset POSIX ERE and Python share:
#          no [[:class:]], no lookaround, no backreferences.
#   ALLOW  optional. A hit whose whole matched text matches ALLOW is not a leak.
#          This is how an org or email domain is allow-listed.
# Lines starting with # and blank lines are skipped.
#
# Private names that must not be committed go in an out-of-tree file named by
# ARCHITECT_LEAK_DENY_FILE (one name per line; matched as whole words). Unset
# means skipped. CI does not set it.
# scripts/architect_export.py also reads this table and REQUIRES a deny file (#9171).
