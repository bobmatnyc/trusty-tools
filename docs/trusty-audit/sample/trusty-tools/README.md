# Sample: trusty-tools self-audit report

This directory holds a sample due-diligence report generated by pointing
`trusty-audit` at this workspace itself — a self-audit rendered 2026-08-23.
It ships as a worked example of the full output the toolchain produces:
`2026-08-23-technical-due-diligence.md` is the main report,
`2026-08-23-technical-due-diligence-authorship.md` is the companion
authorship / key-person-risk section, `2026-08-23-technical-due-diligence.json`
is the machine-readable twin of the main report, and `investigation.json` is
the underlying tga investigation database that grounds it.

The report was produced by trusty-audit 0.9.0 and trusty-review 0.25.0
(published 2026-08-23), with tga 3.3.2 supplying the authorship data, at
engagement workdir `dogfood-audit-rerun4`. The render was hands-off — no
manual editing after generation — and was adversarially graded ACCEPTABLE on
2026-08-23.
