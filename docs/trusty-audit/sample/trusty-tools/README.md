# Sample: trusty-tools self-audit report

This directory holds a sample due-diligence report generated by pointing
`trusty-audit` at this workspace itself — a self-audit rendered 2026-08-21.
It ships as a worked example of the narrative output the toolchain produces:
`2026-08-21-technical-due-diligence.md` is the main report,
`2026-08-21-technical-due-diligence-authorship.md` is the companion
authorship / key-person-risk section. Raw JSON twins and the underlying
tga investigation database are intentionally excluded — this is the
narrative package only.

The report was produced by trusty-audit 0.8.0 and trusty-review 0.22.0 at
main commit `e7cea9904`, with `anthropic/claude-opus-4.8` (via OpenRouter) as
the adversarial reviewer. It passed adversarial rubric grading with a verdict
of ACCEPTABLE, carrying nine known minor defects tracked for the next
iteration. The complexity/analyze lane in this report is intentionally
gap-marked rather than populated, per the stale-index guard — the trusty-analyze
index behind it was not fresh enough to ground that section's findings.
