# Why Trusty-MPM

Engineering presentation, October 2, 2026.

- [Markdown deck and speaker notes](presentation.md)
- [Animated HTML deck](presentation.html)

The HTML uses relative image and font files in `assets/`. Keep this directory together when copying or serving the deck. The font license files are included. Links to the live console require the presenter’s local Trusty Console on port 7788.

For a browser preview, serve this directory with a local static web server and open `presentation.html`. The presentation supports keyboard reveals and animated data flow.
