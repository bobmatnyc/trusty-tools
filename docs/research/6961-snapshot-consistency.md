# HNSW snapshot consistency (#6961)

Existing implementation: `core/store/usearch_store.rs::UsearchStore::save` serializes saves with `save_lock`, clones the key map, and later serializes the graph. `usearch_impl.rs` changes maps and graph in separate lock scopes. `usearch_recover.rs` preserves empty/shrink refusal and staged snapshot recovery. `service/reindex/hnsw_swap.rs` publishes sidecar before binary to keep the key allocator ahead after an interrupted swap.

Contract: `save(&self, &Path) -> anyhow::Result<()>` and all public store interfaces stay unchanged. A saved graph and sidecar must describe one completed mutation boundary. Inserts, deletes, batches, key rewrites, recovery, requantization, and demotion must not interleave with capture. Searches retain their existing locks. `save_lock` becomes the outer mutation gate, acquired before graph/map/path locks; internal promotion and adoption run under their caller's gate and must not reacquire it. Requantization releases the gate before calling public `save`.

Publication must stage both files before replacing either and publish sidecar before binary, following the existing staged-swap contract. A sidecar staging or rename failure leaves the previous binary untouched. Removal credit clears only after both files publish. Existing empty/shrink/torn-pair guards remain authoritative; two separate filesystem renames are not an atomic transaction and an interruption can leave an older binary with a newer sidecar. Cross-process writers and a new persistence format are outside this change.

Regression coverage will poll real save and mutation futures at lock boundaries, assert no partial key-map mutation crosses capture, then cold-load and query persisted vectors by ID. Failure cases cover sidecar staging/rename and binary publication errors; existing cancellation, shrink, recovery, demotion, requantization and staged-swap tests must retain their behavior. Required verification is Rust test-ladder rung 5, with parent-coordinated independent review and live recovery after tests.
