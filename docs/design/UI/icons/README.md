# Trusty Agents identity

This treatment follows the Foundry guidance in `docs/design/UI`:

- rust is the signal, on a paper or Night Shift oxide field;
- the robot is a colleague and appears only at brand moments;
- flat geometry, square machine eyes, restrained radii, and no gradients;
- `TRUSTY AGENTS` uses Chakra Petch; `UNIT-04 · MPM ORCHESTRATION` uses
  uppercase IBM Plex Mono.

## Logo suite

- `trusty-agents-logo.svg` — primary horizontal lockup for paper/light fields.
- `trusty-agents-logo-reversed.svg` — Night Shift lockup for dark oxide fields.
- `trusty-agents-mark.svg` — standalone UNIT mark for constrained spaces.
- `trusty-agents-app-icon.svg` — three-robot PM model for app stores and launchers.
- `trusty-agents-favicon.svg` — optically simplified three-robot browser mark.

Do not place the robot on every card or use rust for competing accents in the
same region. Keep clear space around the lockup equal to the width of one robot
eye. Do not recolor, add shadows, put the mark in a circle, or remove the
`UNIT-04` descriptor from the primary brand lockup.
