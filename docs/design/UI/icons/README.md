# Trusty Agents identity

This treatment follows the Foundry guidance in `docs/design/UI`:

- rust is the signal, on a paper or Night Shift oxide field;
- the robot is a colleague and appears only at brand moments;
- flat geometry, square machine eyes, restrained radii, and no gradients;
- `TRUSTY AGENTS` uses Chakra Petch; `UNIT-04 · MPM ORCHESTRATION` uses
  uppercase IBM Plex Mono.

## Logo suite

- `trusty-agents-logo.svg` — primary horizontal lockup for paper/light fields.
- `trusty-agents-logo-reversed.svg` — Night Shift lockup for dark oxide fields.
- `trusty-agents-mark.svg` — standalone UNIT mark for constrained spaces.
- `trusty-agents-app-icon.svg` — three-robot PM model for app stores and launchers.
- `trusty-agents-favicon.svg` — optically simplified three-robot browser mark.

Do not place the robot on every card or use rust for competing accents in the
same region. Keep clear space around the lockup equal to the width of one robot
eye. Do not recolor, add shadows, put the mark in a circle, or remove the
`UNIT-04` descriptor from the primary brand lockup.

# Trusty Console identity

The console is the operator station the UNITs report to, so its persona is one
robot seated at a dashboard panel rather than the agents suite's robot crew. It
follows the same Foundry guidance as the section above — rust on paper or Night
Shift oxide, flat geometry, square machine eyes, restrained radii, no gradients
— and reuses the agents head geometry unchanged, so the two read as the same
model of machine doing different jobs.

- `TRUSTY CONSOLE` uses Chakra Petch; `UNIT-05 · SERVICE CONSOLE` uses
  uppercase IBM Plex Mono.
- The three panel readouts stand for the service cards the console watches; they
  are part of the mark and are never restyled to mean live status.

## Logo suite

- `trusty-console-logo.svg` — primary horizontal lockup for paper/light fields.
- `trusty-console-logo-reversed.svg` — Night Shift lockup for dark oxide fields.
- `trusty-console-mark.svg` — standalone operator mark for constrained spaces.
- `trusty-console-favicon.svg` — optically simplified browser mark; drops the
  arms, which muddy at 16px.

The prohibitions above apply unchanged: no recoloring the robot, no shadows, no
circular clip, and the `UNIT-05` descriptor stays on the primary lockup.
