ROBOT ACTIVITY STATES
FOUNDRY MOTION SPEC · EVENT-DRIVEN MARK ANIMATION

The mark is the activity indicator. Idle units blink slowly (every 4s). When events stream through, the antenna emits expanding rings — one ring per event burst. Working units double-blink. Motion is subtle, loopable, and never blocks reading.

IDLE
slow blink · 4s cycle · nothing else moves
RECEIVING
antenna rings expand · one per event burst
WORKING
double-blink + gentle head tilt · long-running job
MOTION GUARDRAILS
Rings: 1.4s ease-out, max 2 concurrent, rust stroke fading to 0 — trigger per SSE event, throttle to ≤2/s. Blink: scaleY on the eyes only, never opacity. Working tilt stays within ±4°. Respect prefers-reduced-motion: rings become a static halo, blinks stop. Keyframes ship in tokens.css's companion foundry.css.
