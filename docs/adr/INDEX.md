| [0029](./0029-msrv-1-94-and-edition-policy.md) | MSRV 1.94 and per-crate Rust edition policy | Accepted | Supersedes 0003. | [0030](./0030-sessions-own-many-workstreams-from-the-tm-checkout.md) | A session owns many workstreams and lives in the tm checkout | Proposed | Reverses trusty-mpm's 1:1 session↔workstream binding (DOC-52 §1.5's "permanent, sanctioned" exception) to 1:N. A session's home is the **tm checkout** — the tm-created managed directory, not the user's own clone — refreshed at every new session and restore by fetch + fast-forward-only, never `reset --hard`, because the directory is shared with the user and their editors. Its pane is never `cd`-ed away, so the missing transition out of a workstream is dissolved rather than implemented; workstream branches are cut explicitly from `origin/<default>`, so a skipped fast-forward costs nothing. A workstream is one worktree + one branch + one PR; agent worktrees are its children, reaped when the agent exits. The ~5-workstream limit is an advisory, configurable **attention** cap, freed at merge, never blocking. Reverses #1590's launch target without crossing the config-isolation boundary #1590 defends. Normative encoding: [DOC-66](../specs/DOC-66-session-workstream-model.md) | crate `trusty-mpm` |

## Notes

- **ADRs 0001–0013** were grandfathered as Accepted without re-vetting when DOC-46 (this spec) was introduced.
- **Future ADRs** (0014+) must include a "Related Decisions" section (DOC-46 §3) documenting consistency vetting before acceptance.
- **Crate-specific decisions** (if a crate maintains `docs/<crate>/decisions/`) are tracked in that crate's own index.
- **Superseded ADRs** remain in this index with status "Superseded by NNNN" for historical reference.
