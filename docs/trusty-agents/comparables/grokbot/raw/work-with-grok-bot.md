# Work with Grok Bot

## Bots

A Bot is a durable AI teammate with a name, a job, its own conversation, and
working context that develops over time. Create a separate Bot when the work has
a distinct goal, set of tools, working style, approval boundary, or recurring
schedule.

An account can have up to **50 Bots and group chats combined**.

### Create / edit / organize

- New → Create new agent; Edit Profile for name, title, description, avatar.
- Pin active Bots; Sidebar Sections sync desktop ↔ iOS.
- Hide from sidebar without deleting work or pausing routines.
- Duplicate: copy carries profile, settings, enabled skills, routines, avatar —
  **not** conversation history, learned memory, or attachments.

### Share a Bot

Public share link exposes configuration (identity, description, skills, routines).
Recipient gets a copy on their account — **not** your computer, logins, or
conversation history. Teams/Enterprise admins control public template sharing.

### Delete a Bot

Removes profile, conversation, and routines. Files and sign-ins on the shared
computer aren't isolated per Bot and can remain.

### What a Bot remembers

Stable preferences, important facts, and summaries. Memory is not a substitute
for an authoritative source — verify important facts from source systems; put
safety boundaries in the description rather than in memory.

## Messaging and collaboration

- Paste text, links, images; attach files; `/` skills; `@` mentions; threads;
  reactions; send another instruction while work is in progress; "Stop now".
- Stopping doesn't undo actions already completed.
- Direct message from you takes priority over background work.

### Attachments (desktop)

| Limit | Value |
| --- | --- |
| Attachments per message | 6 |
| Documents, images, audio | 25 MB each |
| Video | 200 MB |

Supported: images, audio, video, PDFs, Office, CSV, JSON, YAML, source code,
HTML, email files, notebooks.

### Group chats

Select **2–6 Bots**. Write normally or `@` one teammate; `@everyone` for
group-wide updates. Bot-to-group handoff messages are text-only; send images
DM when needed.

### Hand work between Bots

Async messages between Bots; visible handoffs. Ask for a single owner at each
stage.

### Reviewable results

Specify artifact + acceptance criteria. Separate facts / assumptions / completed
actions / waiting approvals / unresolved questions. Prefer source links,
screenshots, timestamps, action log.
