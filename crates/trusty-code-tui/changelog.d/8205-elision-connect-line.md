Fixed
- `text::elide_middle` keeps the repository directory name when it shortens a path. A worktree path under `<repo>/.claude/worktrees/<name>` used to lose the repo name at the banner's 54-column budget while leaving columns unused, so the one name identifying the checkout was the first thing dropped; the deepest-components run is now replaced by `…/<repo>/…/<tail>` when it does not reach the repository, and the repo name is the last thing surrendered. (#8205)
- The chat pane no longer clips the tail of any line it wraps. Its height was computed from logical line count while the pane renders through a wrapping `Paragraph`, so a line wider than the pane was under-reserved by a row and ratatui dropped the continuation — at 80 columns the connect line lost `home <path>`, the home directory the launch line exists to name. Height, bottom-pinning and the published scroll cap now all count wrapped rows. (#8205)
