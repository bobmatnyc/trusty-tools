Added
- `Bundle` (SPEC-OKF-01 §4.3, #10746): `open` canonicalises an existing root and reads every concept leniently with findings (foreign paths, symbolic links, fold-key twins, out-of-band edits to verified concepts); `get`, `put`, `verify`, `move_concept` and `regenerate_indexes`.
- `Bundle::put` applies §2.10: a content change moves every `verified[]` event to the verification record under `_sources/verification/`, removes `verified`, sets `generated`, and appends one `log.md` entry; a malformed owned `verified`/`generated` moves to its `legacy_` key with its raw bytes. A later `stale_after` on a human-reviewed concept needs a `human:` actor or a `verify`.
- `Bundle::verify` binds an event to the content hash the verifier saw; `verification_state` and `verification_events` read the record. `format::content_hash` and the lifecycle key set.
- `bundle::paths` (§2.11): root must exist, no write crosses a symbolic link, writes go through a temporary file and a rename, and a target whose case- and Unicode-folded path equals another file's is refused with `fold_collision`.
- `regenerate_indexes` writes OKF §8 `index.md` files, writes zero bytes on a second run, and never touches an `index.md` without a generator marker. `bundle::graph` holds the graph reader moved from trusty-agents.
