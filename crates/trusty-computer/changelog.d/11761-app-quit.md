Added
- `computer_quit` MCP tool (broker tool `quit_app`, FILTER): asks the granted app to quit gracefully with the standard quit Apple event, as its own Quit menu item would, so it can save or prompt first. No signal is sent; the driver's `kill_app` (`kill -9`) stays DENY. It needs the grant flag `app_quit`; it is neither a default tool nor grantable by its tool name (#11761).
- Scoping: a call names exactly the granted `pid` (`pid_out_of_scope` otherwise) and the granted `bundle_id` (`app_out_of_scope` otherwise); any other argument is refused `quit_arg`. The broker re-checks that the pid still runs the granted app before the request, and the request itself, addressed by pid, is refused when the app there does not report the granted bundle id. The audit `done` line records `quit_bundle_id` (#11761).
