Added
- `computer_focus`, `computer_move_window` and `computer_resize_window` MCP tools (broker tools `focus_window`, `move_window`, `resize_window`, FILTER). Focus brings the granted window to the front; move sets its top-left corner in desktop points and keeps its size; resize sets its size and keeps its corner. All three need the grant flag `window_management`; none is a default tool or grantable by its own name (#11696).
- Pid scoping: each call must name the granted pid (`pid_out_of_scope` otherwise) and the granted window (`window_out_of_scope` otherwise), checked before any driver call. The broker then reads the granted pid's windows from the daemon and refuses `window_not_in_granted_app` unless the window is listed under that pid; a list it cannot read is refused `window_frame_unavailable`. Only then does it drive `bring_to_front` or `set_window_frame` for that one window, and the bounded daemon manifest admits only that pid and window. No call moves the pointer, posts input, or acts on the desktop or another window. The window's frame is recorded in the audit `forward` line; a focus records `activates_app` (#11696).
