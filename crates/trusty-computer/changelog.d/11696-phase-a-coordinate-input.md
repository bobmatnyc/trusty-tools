Added
- `computer_click_at` MCP tool (broker tool `click_at`, FILTER): a left click at window-local coordinates of the granted window, posted to its pid. It needs the grant flag `coordinate_input`; it is not a default tool and cannot be granted by its own name (#11696).
- Delegation-authority bound: the broker reads the granted window's frame from the daemon as the last gate before each click and refuses `coordinates_out_of_bounds` for any point outside it, so a window that shrank since the agent last looked cannot take a click outside the delegated scope. A frame the daemon cannot prove is refused `frame_unavailable`; the frame is recorded in the audit `forward` line (#11696).
- `computer_drag` (broker tool `drag_at`) is listed but refused `drag_unavailable_needs_window_on_top_check` before any check or driver call: cua-driver 0.23.2 drags only in the foreground as global screen input, which could reach a window covering the granted one. Drag is deferred until a window-on-top check exists; the bounded daemon manifest does not list `drag` (#11696).
