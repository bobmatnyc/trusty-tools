Fixed
- The bounded screenshot no longer refuses every capture from cua-driver 0.23.2, which reports `elements_complete: false` on a full walk. A tree now counts as complete when `returned_element_count` and `total_element_count` are both present and equal, the `elements` array holds that many entries, and `degraded` is false or absent; anything else still refuses with `screenshot_unverified` (Refs #11694).
- The bounded screenshot now refuses a window with a password field as cua-driver 0.23.2 reports one: role `AXTextField` with no subrole and a localized `value_description`. Because that text differs by language, any text field whose `value_description` is not empty refuses with `sensitive_content` (Refs #11694).
