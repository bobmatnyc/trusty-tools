Added
- `events.subscribe` with `heartbeat_ms` set sends a `heartbeat { head }` item as soon as the subscription is accepted, before the `since_id` check and any replay, and then every `heartbeat_ms` for as long as it is open, including while the log is read; `head` is the bus's last `seq`, read under its ring lock. A subscription without `heartbeat_ms` gets exactly the frames it got before. `heartbeat_ms` outside 100..=3,600,000 is refused with `invalid_params`. A heartbeat never blocks: one that finds the reader's buffer full is dropped (#10071).
- A resume reads the event log one day file at a time and stops as soon as its reader disconnects, instead of reading every retained day file into memory first (#10071).
