Added
- `trusty-memory palace migrate [<palace> | --all] [--dry-run | --verify] [--yes]` migrates a palace to this binary's format through the daemon's own migration chain: a verified backup under `<data root>/backups/format-migration/<palace>/`, each format step, then a check that the format is current, the `kg.redb` marker and the `palace.json` mirror agree, no `format_migration.json` remains and, when this run migrated, the drawer and triple counts read under the migration's exclusive hold are unchanged. A failed check exits non-zero and names the backup; nothing is deleted. An interrupted migration resumes; a current palace is left alone with no backup and its counts are reported, not compared ([#10094](https://github.com/bobmatnyc/trusty-tools/issues/10094))
- `--dry-run` prints each palace's found and target format, the planned backup, its size and the free space, and writes nothing; `--verify` reports each marker as present, missing or mismatched and whether a backup exists, to check a palace converted by hand; `--all` prints the dry-run table first, checks the total free space, refuses without `--yes` when more than one palace would change, continues past a palace that fails, and reports every palace as migrated, failed or not attempted ([#10094](https://github.com/bobmatnyc/trusty-tools/issues/10094))
- The `palace_migrate` MCP/RPC tool (`palace`, `all`, `mode`, `yes`); the CLI calls it when a daemon serves the data root and runs in-process when none does. A daemon from an older release that has no `palace_migrate` is reported as such, with the restart and offline routes ([#10094](https://github.com/bobmatnyc/trusty-tools/issues/10094))
- The `FormatNeedsMigration` error names `trusty-memory palace migrate <palace>` and `--dry-run` for a palace in trusty-memory's data root, beside the owning-daemon restart (`tm daemon run` for tm-owned palaces); `FormatTooOld` keeps starting the older release's daemon as the route; the `trusty-memory doctor` needs-migration line names the command and shows the backup root ([#10094](https://github.com/bobmatnyc/trusty-tools/issues/10094))
