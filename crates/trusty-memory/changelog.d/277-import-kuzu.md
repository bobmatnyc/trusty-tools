Added
- `trusty-memory import kuzu` discovers kuzu-memory stores (`<project>/.kuzu-memory/memories.db`, walking `$HOME` to depth 5 with `--discover`, plus any `--root`) or takes one with `--from`, and imports their memories and knowledge-graph edges (Entity nodes, MENTIONS, RELATES_TO) into the palace `resolve_palace` names for each project. The store is read read-only through kuzu-memory's own Python interpreter (`--python` overrides it). Re-running is idempotent: each drawer carries its source identity and content hash, unchanged memories and already-active triples are skipped, and a memory changed in kuzu since import is reported and rewritten in place only with `--update`. `--dry-run` writes nothing and leaves no export file behind. Writing requires the daemon to be stopped.
