- `palace legacy-kg --apply` holds back every legacy drawer the dream dedup pass would merge: a verbatim repeat inside the import, or a drawer scoring at least the dream threshold (0.95 cosine) against a live drawer or one already kept. Live drawers that have no vector are embedded before the screen, so the screen sees them too; any it still cannot embed are counted in the report as not screened. The report lists the first 20 held-back drawers with the drawer each duplicates and the score, then "… and N more". A screen that cannot embed fails the apply before any write. With `--no-embed` or `--include-content-duplicates` the screen does not run; the dry run and the apply report both name the flag and say the dream pass may merge the imported drawers (#8729).
