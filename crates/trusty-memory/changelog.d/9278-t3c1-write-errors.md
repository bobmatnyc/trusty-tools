Breaking
- `engine::retrieval::PalaceHandle::{flush, remember, remember_with_options, forget}` return `Result<_, engine::EngineError>` instead of `anyhow::Result`. `EngineError` gains three variants: `Kg(KgError)`, `Hnsw(HnswStoreError)` and `VerifyNotStored(retrieval::VerifyNotStored)`. A Tier C slot that committed without its verify command is `EngineError::VerifyNotStored`, which names the drawer. A KG or vector-store error that the write path raises with no context message is `Kg` or `Hnsw`. A filter refusal, a write timeout, a read-only handle and every other failure are `Other`, which keeps the whole text. `?` into `anyhow` still compiles, but `downcast_ref::<VerifyNotStored>()`, `downcast_ref::<KgError>()` or `downcast_ref::<HnswStoreError>()` on the resulting error now returns `None`: downcast to `EngineError` and match the variant ([#9278](https://github.com/bobmatnyc/trusty-tools/issues/9278))
