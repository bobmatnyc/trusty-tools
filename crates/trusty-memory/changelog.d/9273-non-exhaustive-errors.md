Breaking
- Every public error enum is now `#[non_exhaustive]`, so a later variant is not a semver break. A `match` on one of these from outside trusty-memory needs a `_` arm. Newly marked in `trusty_memory::engine`: `ChatSessionStoreError`, `ChunkCommitError`, `FilterReject`, `L1CacheError`, `OpBudgetError`, `PalaceNotEmpty`, `PayloadStoreError`, `RecordError`, `WriteTimeout`, `WriteTxnError`; elsewhere in the crate: `commands::kuzu_import::KuzuImportError`, `kg_write::KgWriteError`, `service::rename::RenameError`, `service::types::ServiceError`, `transport::methods::kg::TripleIdError`. `scripts/check_non_exhaustive_errors.sh` fails CI on a new unmarked one ([#9273](https://github.com/bobmatnyc/trusty-tools/issues/9273))
