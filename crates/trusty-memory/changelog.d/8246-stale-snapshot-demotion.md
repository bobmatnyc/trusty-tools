Fixed
- Recall demotes stale session snapshots below current rulings: a drawer tagged `status`, `resume-target`, `snapshot` or `session-snapshot` (or typed `SessionEvent`) keeps `0.5 + 0.5 * 0.5^(age_hours / 24)` of its score, so an old snapshot no longer outranks a newer ruling on the same subject. Ruling-tagged drawers and live `fact_key` slots are exempt; nothing is deleted. Applies to `memory_recall`, `memory_recall_deep`, `memory_recall_all` and the HTTP recall routes (Refs [#8246](https://github.com/bobmatnyc/trusty-tools/issues/8246), [#9142](https://github.com/bobmatnyc/trusty-tools/issues/9142))
