Fixed
- Recall demotes stale session snapshots below current rulings: a drawer tagged `status`, `resume-target`, `snapshot` or `session-snapshot` (exact tag match), or typed `SessionEvent`, keeps `0.5 + 0.5 * 0.5^(age_hours / 24)` of its score; a future `created_at` counts as age zero. Ruling-tagged drawers and live `fact_key` slots are exempt; nothing is deleted. Surfaces that demote: the MCP tools `memory_recall`, `memory_recall_deep` and `memory_recall_all` (ready and embedder-warming paths, and the daemon RPC methods that forward to them), `MemoryService::recall`, `MemoryService::recall_all` and the new `MemoryService::recall_ranked`, the chat tools `recall_memories` and `memory_recall_all`, and the chat context injection, which now route through those service methods. Each surface fetches about `2 * top_k` candidates (capped at 200) before demoting, so a hit just past `top_k` can be lifted; a hit ranked below that window is not. The score sort uses a total order, so a NaN score cannot unorder the others (Refs [#8246](https://github.com/bobmatnyc/trusty-tools/issues/8246), [#9142](https://github.com/bobmatnyc/trusty-tools/issues/9142))
