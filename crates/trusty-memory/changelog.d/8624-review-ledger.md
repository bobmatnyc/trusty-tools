Added
- `trusty-memory import kuzu review record|status|finish` reviews a `--export-refusals` run. `record --run <run> --key <key> --verdict admit|admit-redacted|keep-refused [--op redact_span:<i>|delete_span:<i>|drop_line:<i>]` appends one agent verdict per exported row to `<run>/ledger.jsonl`, created 0600. Each line carries the row's ledger key, the secret filter version and a digest of the verdict. `record` refuses any admit for a row holding an auto-refuse span, a verbatim `admit` outside the carve-out, an op naming a span the row lacks, and a second verdict for one row. `status` counts reviewed and pending rows; `finish` seals the ledger, after which nothing more can be recorded ([#8624](https://github.com/bobmatnyc/trusty-tools/issues/8624))
- `trusty-memory import kuzu --review-ledger <path>` applies a sealed review ledger. A redacted row is screened again and imported through the normal write path; a row still flagged after its ops stays refused. A verbatim `admit` covers only `mixed_case_alnum` spans and `base64_blob` spans below 4.5 bits/char or shorter than 24 chars, and the drawer is tagged `kuzu-review:override` so it can be retracted. A key, filter-version or digest mismatch, a duplicate verdict, or an auto-refuse row leaves the row refused; an unsealed ledger, one changed after its seal, or one with an unreadable line aborts the run before any store is read ([#8624](https://github.com/bobmatnyc/trusty-tools/issues/8624))
