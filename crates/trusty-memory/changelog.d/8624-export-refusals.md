Added
- `trusty-memory import kuzu --dry-run --export-refusals` writes the rows the secret screen refuses, masked, to `~/.trusty-tools/kuzu-review/<run>/masked.jsonl` for review. The run directory is created 0700 and the file 0600, and the export refuses a destination inside a git work tree or the palace data root. Each line carries the store, the memory id, the masked content, each span's rule and shape, the secret filter version and a sha256 ledger key; the raw secret is never written or printed. Rows of the `provider_prefix`, `aws_key_id`, `private_key_block` and `jwt` rules, rows with a secret-shaped id, and refusals no span locates are counted and never exported. The flag requires `--dry-run` ([#8624](https://github.com/bobmatnyc/trusty-tools/issues/8624))
