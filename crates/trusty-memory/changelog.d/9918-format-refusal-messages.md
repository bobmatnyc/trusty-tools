Changed
- The `FormatNeedsMigration` and `FormatTooOld` error messages say what to do next. `FormatNeedsMigration` no longer says "one behind": it names the palace's format and tells the operator to restart the daemon that owns the palace (the trusty-memory daemon, or `tm daemon run` for the Session Manager and portfolio palaces), which migrates it behind a verified backup, then retry, and to run `trusty-memory doctor` if that daemon is already running. `FormatTooOld` tells the operator to install a release that migrates the palace's format, start its daemon once, then retry with this release ([#9918](https://github.com/bobmatnyc/trusty-tools/issues/9918))
