Added
- The daemon re-embeds drawers stored before chunking in the background, with no operator command. A ticker started with the other maintenance loops runs one bounded `reembed_slice` per tick on the next palace whose `chunk_backfill.json` marker is not complete, rewrites the marker from progress recomputed from the index, and stops on shutdown, mid-slice included. An embed error, store error or ledger error backs off and is retried later; after an embed timeout no slice starts until a probe embed succeeds. Only the process holding maintenance runs it, and it records no recall access. Tune with `TRUSTY_CHUNK_BACKFILL_TICK_MS`, `_BUSY_SECS`, `_ERROR_BACKOFF_SECS`, `_IDLE_SECS`, `_PROBE_SECS`; set `TRUSTY_CHUNK_BACKFILL_DISABLED` to turn it off (#9735).
- `palace_embed_sweep` reports each palace's backfill progress as `chunk_backfill` (`total`, `done`, `pending`, `failed`, `state`) (#9735).
