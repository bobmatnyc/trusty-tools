Security
- The secret gate refuses a URL that carries a credential in its userinfo (`https://user:pass@host/path?x=1`, including a password holding a raw `#` or `?`), its query string or its fragment. A parameter is a credential by name, matched after lowercasing and reading `-` as `_`: a name ending in `token`, `signature`, `credential` (value of 8 bytes or more), `password`, `passwd`, `pwd`, `secret` (any value, so `?password=hunter2` is refused), or `sig`, `key`, `auth` as a whole word (`x-api-key`, `secret_key`; `key` and `auth` need 16 or more letters and digits, so `?sort_key=asc` and `?keyword=rust` stay accepted). Any parameter value that is itself credential-shaped is refused too. Before, a `?`, `&` or `#` in the URL let these through ([#9748](https://github.com/bobmatnyc/trusty-tools/issues/9748))
