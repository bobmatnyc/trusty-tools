Fixed
- **`cargo test -p trusty-memory -- --include-ignored` could only fail.** The four `concurrent_perf` tests still POSTed `/rpc` and `GET /health` at `http://127.0.0.1:7070` and panicked when nothing answered, so ADR-0032 left them red by construction. They stand up their own daemon on a temp socket now: deterministic, off the operator's real palaces, and measuring one machine's daemon rather than whatever was already running on it ([#6286](https://github.com/bobmatnyc/trusty-tools/issues/6286))
  - the burst test gets its own 120s per-request budget. Every write in a 500-way simultaneous burst serialises behind redb's exclusive write lock, so the tail is the queue: at 30s, 49 of 500 requests hit the wall and were counted as DROPS by an assertion that is about drops. The latency distribution the test prints is where the queue depth is reported
