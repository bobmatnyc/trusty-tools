Added
- `trusty-memory audit secrets --count-only [--palace <id>] [--json]` re-screens every stored drawer with the current `check_secret` filter and prints counts only: drawers scanned, drawers refused, a per-`FilterReject` breakdown, and two `KEY=value` counters (`key_value_first`, `key_value_only`) for the value half #8589 started screening. No drawer text, id or token preview is printed. Each palace store is read from a private temporary copy, so the scan writes nothing to any palace, takes no lock, and is safe while the daemon runs. It exits non-zero when any palace could not be read (#8645).
