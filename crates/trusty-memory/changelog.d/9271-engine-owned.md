Changed
- trusty-memory now owns the storage engine: `trusty_memory::engine` is a module of this crate, compiled under every feature set including `--no-default-features`, instead of a re-export of `trusty_common::memory_core`. Item paths under `trusty_memory::engine` are unchanged. Two visible effects: a palace backup's `manifest.json` `writer_version` is now trusty-memory's version (the number `--version` prints) rather than trusty-common's, and the engine's log events carry the `trusty_memory::engine::…` target, so `RUST_LOG=trusty_common=…` no longer selects them ([#9271](https://github.com/bobmatnyc/trusty-tools/issues/9271))
