Changed
- `tm fleet init` seeds the Architect's records in `local/` instead of `records/`: `local/state.md`, `local/actions.md`, and new templates for goals, the user profile, instance facts (`local/instance.md`), a per-project template (`local/projects/_template.md`), the owner model (`local/owner/`) and the mandates schema (`local/mandates/`). An existing Architect keeps its files; nothing is moved (#9997).
- The Architect skills `tm-fleet-check` and `tm-context-refresh` deployed at every Architect launch now name `local/`. A copy of the earlier text that nobody edited is refreshed; an edited copy is kept (#9997).
- `ShippedSkill` no longer has a `source` field: the content file is always `architect/skills/<stem>.md`, read through `ShippedSkill::source()`. `ArchitectSeed::load_from` and `load_skills_from` load a given skill table, so a new Architect skill is one `SHIPPED` entry plus its content file (#9997).
