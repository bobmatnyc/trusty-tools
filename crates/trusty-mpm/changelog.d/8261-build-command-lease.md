Added
- `tm build-lease -- <command>` runs a heavy build under a machine-wide build slot (#8261, absorbing #8297). The slot is a kernel `flock` on `~/.trusty-mpm/build-slots/slot-K.lock`, held for the build's whole life and released by the kernel however the build ends, so a long cold compile can no longer lose its slot to a 45-minute lease TTL. A broken slot file is skipped, never a reason to lift the cap. When no lease can be taken at all, the build runs only while the process census counts fewer than `builders.max_concurrent` builds without a lease; when the census cannot be read either, nothing bounds the build and it does not run. The wait is bounded by `builders.lease_wait_secs` (default 90 s, at most 600 s, and shortened to fit a Bash call's own timeout); on timeout it exits 75 naming the holders, the memory-pressure signals, the load and the ceiling. Every decision is logged by the daemon.
- Only a `CARGO_TARGET_DIR` equal to the machine's shared target directory is moved to the held slot's private directory; an unset one (cargo's `./target`, a repo's `build.target-dir`) and any other pinned one are left alone. When the slot's directory cannot be made, a build inheriting the shared directory exits 75 without running rather than build where concurrent worktrees overwrite each other. A slot that last built a different worktree has that worktree's crate fingerprints cleared first, so cargo cannot report the new worktree's crates "Fresh" from the old one's build.
- The `PreToolUse` guard rewrites heavy builds — `cargo build/test/clippy/check/doc/install/run/bench`, their aliases `b/t/c/d/r`, and `fix`, `rustc`, `rustdoc`, `publish`, `package`, `nextest`, `llvm-cov`, `miri`; configurable as `builders.heavy_build_commands` — to run under `tm build-lease`, before the subagent exemptions, so dispatched agents' builds are capped too. Composed commands, `case` arms, `sh -c`/`xargs` wrappers and `$(…)` substitutions are rewritten in place, and the lease goes outside `sudo`/`doas`; nothing inside a here-document body is ever rewritten. A heavy verb that compiles nothing — `--help`, `-h`, `--version`, `-V`, `cargo install --list` — is not leased, so a read-only agent's checks never wait for a slot. Inside an isolation worktree the lease is inserted without the output-compression wrap (#7477). `tm hook` emits the same rewrite so the two hooks agree.
- Claude Code permission rules: a command that matches a `deny` or `ask` Bash rule is never rewritten, so that rule keeps applying to the original command. An `allow` rule written for the original (e.g. `Bash(cargo test:*)`) no longer pre-approves the rewritten `…/tm build-lease -- cargo test`; outside bypass-permissions mode add an allow rule for the lease program.
- Admission reads memory PRESSURE (macOS `kern.memorystatus_vm_pressure_level` and `kern.memorystatus_level`; Linux PSI, cgroup PSI in a container, or `MemAvailable`), the load average, and a process census that counts compiler groups holding no lease. New `[builders]` keys, read by the new `core::build_lease::config::BuildLeaseConfig` so `BuildersConfig` keeps its published shape: `memory_pressure_max`, `min_available_pct`, `lease_wait_secs`, `heavy_build_commands`, `count_foreign_builds`.
