Added
- `tm secrets exec [--env NAME=KEY]... [--stdin KEY] -- <command>` runs a command with project keys in its environment or on its stdin. tm spawns a helper, grants that helper's pid the named keys on the trusty-secrets socket, hands it the grant token over a pipe, and the helper resolves each key once and execs the command in place. No token or value reaches any argv or tm's environment; the command gets only the token's fd number, in `TRUSTY_SECRETS_TOKEN_FD`. Any refused grant, malformed token or key that does not resolve runs nothing and exits 1. The grant is revoked on exit and when tm gets SIGINT, SIGTERM or SIGHUP, which it forwards to the command. When stdout is not a terminal, stdout and stderr are scrubbed of every injected value of 8 characters or more (#9621).
