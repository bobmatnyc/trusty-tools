Changed
- `tm build-lease` frees compile capacity once cargo releases its build lock (#8692). A leased `cargo test` whose test binaries run, or a `cargo run` program, keeps its slot and target directory until it exits, but no longer counts against `builders.max_concurrent`, so another leased build can start beside it. The holder record gains an additive `phase` field (`compile`, then `run`); a record without it, or an unreadable one, counts as compiling, and an older `tm` reading a `run` record counts the slot as held. `tm build-lease status`, `--census` and the `builder_cap` doctor row mark a run-phase holder `running`. A run-phase holder's later compilers (a `cargo watch` rebuild) count as foreign builds.
- New key `builders.max_run_slots` (default: the ceiling) bounds the slot directories run-phase holders keep: at `ceiling + max_run_slots` owned slots a new build waits, naming the cap.
