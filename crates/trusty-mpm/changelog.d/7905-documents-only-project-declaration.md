Added
- `.trusty-mpm.toml` gains `documents_only`. A repository that declares it admits source-classified writes and commits in its own main checkout, so a prose repo whose CLAUDE.md forbids worktrees can land a `.py` rename it previously could land by neither route (#7905). The declaration counts only when it is committed at `HEAD` — an untracked or uncommitted one grants nothing — and staging a change to the `documents_only` key is itself a source-class commit, so a project can only declare itself through a worktree branch and a reviewed pull request. Absent, `false`, unreadable or malformed leaves the ADR-0044 boundary exactly as it was.
