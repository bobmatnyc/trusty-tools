Added
- `.trusty-mpm.toml` gains `documents_only`. A repository that declares it admits source-classified writes and commits in its own main checkout, so a prose repo whose CLAUDE.md forbids worktrees can land a `.py` rename it previously could land by neither route (#7905). The declaration counts only when it is committed at `HEAD` — an untracked or uncommitted one grants nothing — staging a change to the `documents_only` key is itself a source-class commit, and in a main checkout every verb that can move `HEAD` onto someone else's commit (`merge`, `rebase`, `cherry-pick`, `revert`, `reset`, `checkout -B`, `switch -C`, `update-ref`, `symbolic-ref`, `am`, `apply --index`) is refused when it would land a different `documents_only` value. A project can therefore only declare itself through a worktree branch and a reviewed pull request. `fetch`, `log`, `show`, `status` and `diff` are unaffected, and absent, `false`, unreadable or malformed leaves the ADR-0044 boundary exactly as it was.
