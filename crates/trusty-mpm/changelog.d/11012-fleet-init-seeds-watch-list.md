Added
- `tm fleet init` creates the Architect's `local/watch.json` when it is absent, from the live `tm-*` tmux sessions mapped to registry keys by session alias, then by session path, plus any project the `CLAUDE.md` `## Watch set` import would add. Each project's record is written first, as `tm fleet project add` does. A session that maps to no project, or to more than one, is skipped with one report line. With no tmux or no `tm-*` session the list is created empty and the report says why (#11012).
- `tm fleet init` never changes an existing `local/watch.json`, even an empty one, and says it left it. A list that does not parse fails the run and is left byte-identical; a record or list write that fails also fails the run. Re-running `init` on an Architect set up before this release seeds its missing list (#11012).
