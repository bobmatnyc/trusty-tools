Added
- An Architect session now gets the owner's standing rules from `local/standing-rules.md` in context at every session start, resume and `/clear`, and on every user turn. The new `tm hook --standing-rules` is registered for Architect sessions only. A file over 2 KB injects only its whole lines plus a notice that the rules were cut, all within the cap, and shows a warning. An absent file does nothing. An unreadable file shows a warning and the turn goes on. (#10960)
