Fixed
- `tm hook --pm-guard`'s secret-file class no longer reads Markdown emphasis as a glob onto a credential family: a glob carrying at most one literal character and no leading `.` now selects no family in particular, the same answer an all-wildcard glob already got. `**A pipe confirms nothing at all.**` in a here-document body, in an `echo`, or in a `gh` comment body was refused as naming `**A` (#7533).
- The same class no longer reads a sentence's full stop as a file extension: `token.`, `secrets.` and `credentials.` at the end of a sentence are prose, not file shape, in both the read guard and the copy/laundering guard, so a here-document of ordinary text is no longer refused as reproducing a secret file into its destination. A dot with a name after it (`note.md`, `.env`, `secrets.rs`) is untouched (#7533).
- `git worktree add`'s operands are now read as a new tree's path and a commit-ish, so a branch name carrying `secrets`/`credentials`/`token` no longer refuses the call — the same narrowing `git branch`, `git push` and `checkout -b`/`switch -c` already had. `worktree list`/`remove`/`prune` keep the previous answer (#7533).
