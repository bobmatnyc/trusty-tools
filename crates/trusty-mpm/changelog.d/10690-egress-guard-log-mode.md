Added
- `[egress_guard] mode` in `~/.trusty-mpm/config.toml`, `"enforce"` (the default) or `"log"`. `mode = "log"` disables enforcement of every `tm hook --egress-guard` deny, the #8878 trust-anchor floor included: the call proceeds, and each deny is still recorded in the denial store and POSTed to the daemon, its reason prefixed `[egress_guard mode=log: recorded, not enforced]` and the POST carrying `"egress_guard_mode": "log"`. The default stays enforce, and only the exact string `"log"` turns enforcement off: a missing key or file, an unreadable or malformed file, and any other value (`"Log"`, `"off"`, `""`) enforce, an unknown value with one warning on stderr. The mode is read on every hook run (#10690).
