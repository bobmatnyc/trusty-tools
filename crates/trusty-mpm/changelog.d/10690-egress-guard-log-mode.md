Added
- `[egress_guard] mode` in `~/.trusty-mpm/config.toml`, `"enforce"` (the default) or `"log"`. `mode = "log"` disables enforcement of every `tm hook --egress-guard` deny, the #8878 trust-anchor floor included: the call proceeds once the deny is recorded in the denial store, and the deny is POSTed to the daemon, its reason prefixed `[egress_guard mode=log: recorded, not enforced]` and the POST carrying `"egress_guard_mode": "log"`. A deny that log mode cannot record (the store append fails, no data directory, `TRUSTY_NO_BUG_CAPTURE` set) is enforced, with one line on stderr. The default stays enforce, and only the exact string `"log"` turns enforcement off: a missing key or file, an unreadable or malformed file, a wrong type, and any other value (`"Log"`, `"off"`, `""`) enforce, an unknown string with one warning on stderr. The mode is read on every hook run, from the user-level config only; a project `.trusty-mpm.toml` cannot set it (#10690).
