Added
- The daemon's `mpm.architect.dashboard.*` methods no longer need a store root from the caller (#10944). A call with no `store`, or a `store` with no `root`, uses `DASHBOARD_ROOT`, else `<ARCHITECT_PROJECT_DIR>/local/owner-queue`, else the one Architect recorded in `~/.trusty-mpm/config.toml`, else `~/trusty-mpm-projects/architect/local/owner-queue`. An explicit `store.root` still wins and is passed on unchanged. A root that cannot be resolved, or whose directory is missing, is an exit-3 error that names the path tried, where it came from and the fix (`tm fleet init`, or pass a root), never an empty list. The MCP tool and `tm architect dashboard` are unchanged.
