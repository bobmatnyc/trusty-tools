Fixed
- A daemon started by `scripts/sandbox_daemon.sh` now runs tmux on a server of its own. The launcher sets `TMUX_TMPDIR=<dir>/data/tmux` (mode 0700) and names the socket it gives the daemon. `tm daemon --sandbox` admits `TMUX_TMPDIR`, and under `TRUSTY_SANDBOX=1` tm spawns tmux only when `TMUX_TMPDIR` is a private directory inside the sandbox data dir and `$TMUX` is unset. Anything else refuses tmux, even with `TRUSTY_MPM_ALLOW_HOST_STATE=1`, so a sandbox never reaches the default socket. The host process table stays closed to a sandbox. When the daemon exits, the launcher stops that server with `tmux -S <socket> kill-server` and touches no other (#9557).
