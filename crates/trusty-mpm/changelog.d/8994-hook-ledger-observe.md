Added
- The daemon now records a Claude Code agent-isolation worktree in the worktree ledger (`~/.trusty-mpm/worktrees.jsonl`) the first time a hook event's `cwd` names `<registered project>/.claude/worktrees/agent-*`, with its branch and session, so `tm worktrees` and the `worktree_registry` doctor row count it without a backfill. After a `SubagentStop` or `SessionEnd` the daemon appends `removed` for an agent tree only when its directory is gone and `git worktree list` no longer names it. tm subscribes to no `WorktreeCreate` or `WorktreeRemove` hook and deletes nothing. A ledger write failure never changes the hook verdict: it is logged and recorded in `worktrees.ingest-failure.json`, which turns the `worktree_registry` row to `Warn`. A tree whose record failed is retried at the next stop event, and the warning clears only when no failed tree remains; a failed registry read never stops later stop events from reconciling (#8994).
