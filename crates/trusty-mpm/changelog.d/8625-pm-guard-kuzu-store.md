Added
- `tm hook --pm-guard` denies any tool call that reads a kuzu-memory store (`memories.db` and its sidecars, a `.kuzu-memory` directory), the kuzu import venv (`kuzu-import-venv`), or the import bridge's `trusty-kuzu-import-*` temp export, and any call that runs `kuzu-memory` or `python -m kuzu_memory`. It covers Bash words, globs that can match one of those names, `Read`/`Edit`/`Write`/`MultiEdit`/`NotebookEdit` paths, `Grep` and `Glob` paths and globs, symlinks to a store, and a working directory inside one. The deny holds under `TRUSTY_MPM_PM_UNRESTRICTED` and `TRUSTY_MPM_DISABLE_HOOKS` and for the Architect, and is audited as `kuzu-store-read` (#8625).
- Any Bash call whose text names both `trusty-memory` and `kuzu` is denied under the guard as `kuzu-store-read`, after quotes, `$` and backslashes are removed and letter case is folded. This covers `trusty-memory import kuzu` and the deprecated `migrate kuzu-data` and `migrate kuzu-memory` aliases. A quoted `--body`, `--title`, `--message`, `--note` or `-m` value is prose and is exempt, unless it runs a `$(…)` or backtick substitution. The rule targets mistakes, not deliberate evasion; the import runs only outside the guard, and a narrowed exception is #9794 (#8625).
