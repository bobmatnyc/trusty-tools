Fixed
- A daemon restart no longer hands a builder slot that a running build still holds to a new dispatch. Each slot handover now records a lease file beside the slot (`.slot-<n>.lease`) naming the holder, the dispatching session's pid and that process's start time. A restarted daemon skips a slot while its lease's owner runs with the recorded start time, inside the 45-minute lease TTL. A dead owner, a reused pid or an expired lease frees the slot. A lease that cannot be read or verified, including a pre-upgrade handover with no lease inside the TTL, keeps the slot rather than freeing it (#8819).
