Added
- Channels config can bind each org to a channel kind (`slack` or `gchat`) with `secret://` credential refs, and map each user to one org. A send resolves only through the recipient's own org channel; a send with no route or through another org is refused. Outbound sends are staged and post only after the owner's Approve on the exact text (SHA-256 digest), exactly once; deny, timeout and free text post nothing, and an unknown outcome is never reissued. Slack DMs post with `chat.postMessage` and `channel = <member id>`. Approvals target the owner's Slack DM for every org, with the dashboard as fallback. The daemon route and MCP tool wiring follow (#10417).
