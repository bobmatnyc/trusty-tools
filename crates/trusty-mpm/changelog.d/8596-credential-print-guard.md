Security

- `tm hook --pm-guard` refuses a Bash command that would print a credential value into tool output: `security find-generic-password`/`find-internet-password` with `-w` (value on stdout) or `-g` (value on stderr), and `gcloud auth [application-default] print-access-token`/`print-identity-token`, when the value reaches the terminal, a printing filter such as `| head -c 50`, an `echo`/`printf`/`cat` argument, or the command-name position. The rule applies to every caller, dispatched agents included. Capturing forms still run: an exit-status existence check with `>/dev/null 2>&1`, `TOKEN=$(…)`, a `$(…)` argument to `curl`, and a pipe to `--password-stdin`, `wc` or `pbcopy`. A credential command the guard cannot parse is refused, not allowed ([#8596](https://github.com/bobmatnyc/trusty-tools/issues/8596), [#8248](https://github.com/bobmatnyc/trusty-tools/issues/8248)).
- The `tm-secrets` skill states the exit-status Keychain check and the in-command token form ([#8596](https://github.com/bobmatnyc/trusty-tools/issues/8596)).
