- A tm-launched PM no longer loads Claude Code built-in tools it never uses. Every PM launch path — the daemon spawn and resume, `tm launch`, `tm connect`, the in-place `tm session start`, the bare-`tm` in-pane relaunch, `tm run`, the GUI "New Session" spawn and the daemon-client launch and connect — sets `CLAUDE_CODE_DISABLE_ARTIFACT=1` and passes `--disallowedTools Workflow,DesignSync`, which removes the Artifact tools, `Workflow` and `DesignSync` from the session. The claude-in-chrome browser tools stay, because `web-qa` drives the browser and a session-level deny reaches subagents. The `Cron*` tools stay, because session resume uses them. A supervisor (Architect) launch keeps every tool (#8992).
