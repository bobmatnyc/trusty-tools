Security
- `tm hook --egress-guard` and `tm hook --pm-guard` no longer slow quadratically on a command dense in `<<`. The issue's 64 KiB `time eval` x12 repro took 129 to 170 s in the egress hook on a debug build, past the 10 s hook timeout, which lets the command through; it now takes about 3 s, and the pm-guard Bash classifier about 0.3 s. Five here-document scan loops are now linear: the walk's pending-operator low-water marks, the operator lookup per `<<`, the line-end search per `<<`, the body and frame queries callers ask per byte, and the check of each arithmetic `<<` against the lines after it. Verdicts are unchanged (#9720).
