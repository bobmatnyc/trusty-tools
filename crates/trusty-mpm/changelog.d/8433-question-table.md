Added
- The daemon now has a durable question table for chat-channel questions, `~/.trusty-tools/trusty-mpm/channels/questions.jsonl` (mode 0600, directory 0700). An id is reserved on disk before a question is sent and is never reused, even after a restart. A question resolves once, and only from its recipient in the conversation it was asked in; a later answer gets the first answerer and time. Any failed write stops the table until it is reopened from the log, a second daemon cannot open the same table, and a log line a correct table never writes (an answer to an unknown question, a Google Chat or unknown channel) stops the table from opening. A table that cannot open is retried on the next use; there is no in-memory fallback. The answer text is not stored, only its SHA-256 and length. Nothing calls the table yet; it is built with the `channels` feature only (Refs #8433).
