Changed
- `session_context_catchup` and `tm sessions catchup` default to a lean answer: the snapshot resolved for the caller (`resolved_snapshot`, `resolved_via`, and a new `resolved_session` record with its summary, in-progress work, next steps and pause-time `git_context`), a new live `git_status` field (a `git status --porcelain` in `project_dir`, at most 40 entries, killed after 5 seconds; `available: false` with an `unavailable: …` error on failure), the supersession, verify and session-ref fields, and `digest: "lean"`. The default no longer returns `sessions`, `recent_commits` or `recent_memory`. `full: true` / `--full` returns the full digest with no watermark, exactly as `full: true` did before; the watermarked manual digest is gone. `all_projects` / `--all-projects` and a non-zero `sessions_offset` now require `full: true` / `--full`. Session-start injection is unchanged (#9883).
