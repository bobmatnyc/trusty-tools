- `tm fleet init` seeds the Architect `scripts/dashboard_pane_tail.py`. Its `session_pane_tail(name, n)` captures the named session's tmux pane, masks it with `mask_pane_text` and returns the last `n` lines (default 40, clamped to 10-200, each line cut at 300 characters). Results are cached in memory for 3 seconds and never written to disk. A failed capture returns a typed failure, never an empty tail. The poller's `capture()` takes a `history` depth so the tail can reach 200 lines, and a `join` flag (tmux `-J`) the tail sets so a soft-wrapped line is masked whole. A secret an application wrapped onto the next row is masked on both rows, so the row below a row that ends in a secret is masked as well (#11065).
