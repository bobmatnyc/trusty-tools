Added
- `tm secrets assign SRC --project owner/repo [--as KEY] [--from-backend B] [--to-backend B]` copies one key of any trusty vault into a named project's vault. SRC is `trusty/<owner>[/<repo>]:KEY` or `secret://<owner>[/<repo>]/KEY`. The value moves inside the trusty-secrets server and never reaches tm, the clipboard or the output; tm prints names only. The project must share the checkout's owner, and under Claude Code it must be the checkout's own project. A re-run replaces the destination value, as `copy` does. Until the project registry ships (#10368), `--project` refuses every project with a fixed error and writes nothing (#11015).
