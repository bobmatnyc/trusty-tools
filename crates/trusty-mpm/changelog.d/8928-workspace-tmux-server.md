Added
- Each workspace has a private tmux server name, `tm-ws-<slug>-<hash>` from its canonical path, and a resolved socket path such as `/private/tmp/tmux-502/<name>` for the sandbox's `allowUnixSockets` entry (`core::tmux_server`, #8928 step 4). `TmuxDriver::on_server` aims every typed tmux command at a named server with `-L`. The daemon's session snapshot falls back to the live `tm-ws-*` servers when the default server does not hold the session, and the Architect's fleet poller lists and captures PM panes on those servers as well as the default one (unless `TMUX_SOCKET` pins a single server). Launching a PM on its workspace server is step 6.
