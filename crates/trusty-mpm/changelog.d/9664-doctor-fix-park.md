Added
- `tm doctor --fix --yes` parks each duplicate trusty-search index the `search_project_duplicate_index` row flags, through the daemon's `search.project.park` (#9664); `--fix` alone lists the parks it would make. It never parks the index of the project the doctor runs in, a second main checkout, or an index the row did not flag, and parks nothing when the project map was not read. Each park is reported as parked, already parked, refused or failed with the reason; a park that is refused, answers without `parked: true` or gets no answer within the time budget is reported as failed, never as fixed.
