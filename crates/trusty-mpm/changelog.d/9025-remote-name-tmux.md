Added
- A managed Claude Code session's remote name now equals its tmux session name (#9025). Every launch path — the daemon's launch and resume, `tm launch`/`tm connect`/`tm session start`, and `tm fleet init`/`tm fleet relaunch` — passes `--name <tmux session>`, and the Architect's `--remote-control` carries the same name. A tmux session renamed after launch is reported by the `tm doctor` `session_names` row, which names the `/rename` that fixes it.
