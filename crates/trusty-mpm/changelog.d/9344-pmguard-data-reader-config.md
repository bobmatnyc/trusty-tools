Security
- pm-guard: a git, gh or tm here-document body is no longer trusted as data when its operator line injects config or may name an alias. `git -c alias.x='!sh' x <<'O'` and its `--config`, `--config-env`, `--exec-path` and `GIT_CONFIG_*` forms run the body through `sh`, so every rule judges it as shell. A git subcommand outside the data builtins (`commit`, `tag`, `notes`, …), a gh first argument outside its core commands, or a prefix assignment also drops the trust, and the rm-root floor judges the body. `git commit -F -` and `gh pr create --body-file -` bodies stay data (#9344).
- pm-guard: the rm-root floor reads every here-document body, whatever program reads it, and denies a line whose program word is `rm`, `rmdir`, `unlink` or `find -delete` with a root-class target (`/`, `~`, `$HOME`, a bare container). Prose that names `rm` in a sentence or a backticked delete stays allowed (#9344).
