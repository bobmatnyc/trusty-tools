Added
- `tm` now carries a standard GitHub Projects board spec, `examples/issue-state/board-v1.yaml`, compiled in (#10275). It declares six standard fields: Status with nine options, Hold (declared off), Start date, Target date, Deployed on and Published on. It also declares three views, the built-in workflow intents and a README template, all taken from the Project #45 capture. Each Status option maps to one `status:*` lifecycle state or declares `label: none`, and the load refuses a spec that breaks the standard set or that mapping. No command reads the spec yet.
- `issue-state.yaml` accepts a `project:` block naming the repo's board: `owner`, `number`, `drop_options` and `extra_fields` (#10275). A `project:` block with an unknown key fails the load, naming the key. trusty-tools' own `issue-state.yaml` names Project #45 with Crate and Agents as extra fields.
