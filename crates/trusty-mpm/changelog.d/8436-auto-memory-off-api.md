Breaking
- The trusty-memory reachability input is gone from the launch API (Refs #8436). Removed: `core::session_launch::prepare_session_with_memory_reachable`, `core::session_launch::prepare_session_for_repair`, `core::deploy_validate::validate_and_repair_reusing_memory`, the `PrepReport::memory_reachable` field, and `core::memory_reachable::{probe_memory_reachable_blocking, resolve_memory_reachable, resolve_spawn_memory_reachable}`. Dropped the `memory_reachable` parameter from `runtime::build_adapter`, `ClaudeCodeAdapter::new`, `prepare_session_for_repair_under`, `validate_and_repair_under` and `daemon::doctor_auto_memory::repair_auto_memory`. Use `prepare_session_with_home` or `prepare_session_with_repo_url_and_exe` in place of the removed preparation entry points.
