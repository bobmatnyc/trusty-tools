Added
- `tm presence local` asks for Touch ID (or the login password) at the Studio and, from the bound Architect session only, writes a presence grant for that session's `claude`: `~/.trusty-mpm/architect-launch/<pid>.presence`, mode 0600, tied to the PID and start time and sealed with an HMAC key kept in the login Keychain, so a grant copied to another process or written by hand is refused. Over SSH, with no GUI session, or from any other session it writes nothing (#8878).
- pm-guard denies the bound Architect's trust-anchor writes unless a valid presence grant exists and was used within the last 120 minutes; the deny names `tm presence local` and never asks in the pane. A grant that is missing, idle, forged, symlinked, unreadable or malformed denies. When Remote Control looks active the deny says so; that grants nothing (#8878).
- `tm fleet bind` binds a running Architect `claude` that no tm launch recorded, from its own tmux pane, after the same Touch ID or password prompt, and grants presence in one step. `tm presence` and `tm fleet bind` are trust-anchor writes for PMs, agents and subagents, which pm-guard denies (#8878).
