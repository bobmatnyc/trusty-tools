Changed
- `tm build-lease -- cargo run …` no longer holds a build slot while the program runs. It leases `cargo build` with the same flags, releases the slot when that build finishes, and then runs the original `cargo run` unleased, which finds the build fresh. A server or REPL started with `cargo run` no longer blocks every other build on the machine (#8261).
- `tm build-lease -- cargo watch …` no longer holds a build slot for the watcher's lifetime. The watcher runs unleased, and every command it starts (`-x`, `-s`, a bare `cargo watch test`, a trailing `-- <cmd>`, or the default `cargo check`, with `--features` applied as cargo-watch applies it) is handed to it as a `-s` command that takes its own lease when it is a heavy build. A `cargo watch` argument shape that cannot be mirrored exactly is refused with exit 75 (#8261).
