Fixed
- Config `tmux.alternate_screen` now decides Claude Code's renderer on every managed launch: `true` starts `claude` with `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=0`, `false` with `=1`. This covers daemon spawn, restart and attach; the `tm launch`, `tm connect`, `tm session start` and client `/connect` launch lines; `tm run`; and the bare-`tm` in-place relaunch. The value no longer comes from whatever environment the tmux server or the launching shell inherited. A settings-file `env` entry still overrides it. A config file that cannot be read never blocks a launch: tm logs a warning naming the file and the error, and falls back to the same value the tmux `alternate-screen` option falls back to (#8405).
