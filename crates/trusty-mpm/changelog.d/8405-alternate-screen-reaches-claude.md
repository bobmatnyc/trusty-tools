Fixed
- Config `tmux.alternate_screen` now decides Claude Code's renderer on every managed launch: `true` starts `claude` with `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=0`, `false` with `=1`. This covers daemon spawn, restart and attach, and the `tm launch`, `tm connect`, `tm session start` and client `/connect` launch lines. The value no longer comes from whatever environment the tmux server inherited. A settings-file `env` entry still overrides it. A config file that cannot be read now fails the launch instead of silently falling back to the default (#8405).
