Added
- Session launch now writes `skillOverrides` into the project's `.claude/settings.json`, turning off skill families the project's detected stack cannot use: `rust-build-performance` outside Rust/Tauri, the web-app family (`claude-in-chrome`, `webapp-testing`, `web-performance-optimization`) for stacks with no web front end, `duetto-design-system` outside React/Next.js, `xlsx` outside Python/JavaScript/TypeScript, and `breeze-voice`/`cto-kb-ingest` for every detected stack. The stack-to-family table in `core::skill_overrides` is the only source. The write merges: existing keys and user-set entries win, a repeat launch leaves the file byte-identical, a file that is not a JSON object is left untouched with a warning, and an undetected stack writes nothing (Refs #7751).
