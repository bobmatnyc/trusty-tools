Added
- `tm install` and `tm fleet init` install the `trusty-browser-mcp` and `trusty-computer-mcp` binaries with `cargo install --locked` when they are missing, then register them at user scope. An existing entry is kept and reported. `tm doctor` reports each server as installed, registered and command-path-exists (G0b). `cargo install` runs with `--root <CARGO_HOME>` and a 10-minute limit, after which it is killed and reported as missing; the doctor rows never rewrite the config. Set `TM_SKIP_MCP_AUTO_SETUP` to opt out of this setup step.
