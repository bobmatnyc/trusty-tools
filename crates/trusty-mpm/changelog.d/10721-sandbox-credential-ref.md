Added
- `scripts/sandbox_daemon.sh --credential NAME=<ref>` hands the sandbox daemon one provider key, `ANTHROPIC_API_KEY` or `OPENROUTER_API_KEY`, by vault reference. `tm secrets exec` resolves the reference, so the value never reaches an argument list, a file or the output. A wrapper clears every other exported variable, and `tm daemon --sandbox --sandbox-credential NAME` admits only that variable, reads it once and removes it from its environment, so the tmux and claude processes it starts do not inherit it. Any other name, an unresolvable reference, or the variable unset refuses and starts no daemon. Without `--credential` the sandbox still admits no credential (#10721).
