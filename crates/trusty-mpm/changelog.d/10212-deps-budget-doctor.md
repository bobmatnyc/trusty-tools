Added
- `tm doctor` has a `deps_budget` row. It counts the entries of `debug/deps` in each shared target under `~/.trusty-tools/cargo-target/<owner>/<repo>` and in each builder slot, and warns at 150,000 entries, the size at which a `deps/` directory starts to stall syspolicyd on every exec. The count stops at the warn line, so the row never lists an oversized directory in full. A missing `debug/deps` is reported as missing and an unreadable one as unreadable (row status Unknown), never as 0 entries. The warning names the repair: with no build running, rename the target's `debug/` aside and delete the old tree. Nothing refuses a build (#10212).
