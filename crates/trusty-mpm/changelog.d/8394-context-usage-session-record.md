Added
- `tm statusline` now records each tick's context-window figures (`total_input_tokens`, `context_window_size`, `used_percentage`) and plan rate-limit figures (five-hour and seven-day `used_percentage` and `resets_at`) to `~/.trusty-mpm/usage/session-context-usage/<claude-session-id>`, stamped with `updated_at`. A null or absent figure is recorded as absent, never as `0`. A failed write leaves the status line unchanged and is logged to stderr (#8394).
- `SessionRecord` gains an optional `context_usage`, and `FleetMetrics` (in `supervisor-metrics.json`, `supervisor_status` and `console_metrics`) gains `context_usage`, one entry per live session, and `plan_usage`, the newest account-wide plan figures. Each reading carries `updated_at` and a `stale` flag, set when the reading is more than five minutes old, because the status line runs only while the pane renders. Older records and snapshots without these fields still load (#8394).
