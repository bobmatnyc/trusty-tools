Added
- The Architect's seeded `task_tag.py` gains `parse_block`, a parser for the structured `il` block that DOC-89 v1 defines for PM turns and agent handbacks (#11133, phase 1). It reads one fenced `il` block of `key: value` lines (required `goal`, `task`, `done`, `pct`, `next`). It returns the first violation for an unknown key, a repeated singleton, a missing required key, a bad id, `pct` outside 0-100 or a secret-shaped span, and never masks or repairs the block. Its records share `parse_pulse`'s fields (`id`, `stamp`, `done`, `est`, `remaining`, `pct`). `parse_handback` returns the block result when a block is present and otherwise falls back to the legacy `Task:` line. No hook calls it yet.
