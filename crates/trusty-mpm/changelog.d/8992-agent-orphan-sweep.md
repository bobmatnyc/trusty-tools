Added
- `tm doctor` has a new `agent_orphans` row. It lists agent files in the shared agent deploy dir that the current bundle no longer ships, such as the retired `ops` agent. `tm doctor --fix-agents --yes` backs up and removes the ones the deploy ledger records as framework-owned whose bytes still match the recorded checksum. A hand-edited file, a user-owned ledger entry, a file absent from the ledger, and a file carrying only the `provenance: framework-owned` stamp are kept and reported with the reason. A missing or corrupt ledger, or an unresolvable bundle roster, removes nothing. Nothing sweeps at launch or deploy, because every PM shares the dir (#8992).
