Added
- The Architect dashboard serves `GET /api/pane?session=<tm-name>&lines=<n>`, a managed session's masked pane tail as `{session, lines, captured_at, truncated}`. Only sessions in the managed set that `/api/fleet` lists are served: any other tmux session, such as a personal shell or the Architect's poller, gets 404 `not_running` with no tmux call, and the route answers 503 `fleet_unavailable` when the managed set cannot be built (#11180). `lines` defaults to 40 and is clamped to 10-200; a non-integer or a value over 6 digits is a 400. The session name must match exactly. It answers 404 `not_running` when no tmux session has that name and 503 `capture_failed` when tmux does not answer. It is architect-mode only and sits behind the Host/Origin guard; pane text is masked by `mask_pane_text` and cached in memory for 3 seconds (#11065).
