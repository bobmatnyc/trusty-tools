Fixed
- A `Running` delegation record whose `SubagentStop` was lost now goes `Stale` after a 15-minute quiet bound instead of holding for six hours. It goes `Stale` only when the agent sent no hook event within the bound and the OS shows no live evidence of it in its own worktree (no process standing in the tree, no running harness lock). A probe that cannot answer leaves the record `Running`. A late stop still ends the record as it would end a `Running` one. Agents with no worktree of their own are never staled this way, and the six-hour sweep is unchanged. Set `TRUSTY_MPM_DELEGATION_QUIET_STALE_SECS` on the daemon to change the bound (#6556).
- `tm hook` now exits non-zero when a `SubagentStop` it could not deliver also cannot be parked on disk, so Claude Code reports the lost stop instead of a silent exit 0 (#6556).
- The daemon's stop-spool drain keeps a parked `SubagentStop` the daemon refuses and retries it on the next reap tick, instead of discarding it and leaving the delegation `Running` (#6556).
