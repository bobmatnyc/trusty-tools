Added
- New `tm hook --egress-guard` hook mode denies every Slack, Gmail, Notion and Google Chat MCP tool, and the mail, chat and message tools of a `gworkspace` server, including read, search and list tools. It matches the MCP server name after lowercasing and dropping separators, so `Slack-MCP` and `claude_ai_Slack` are caught. It applies to subagents and holds with `TRUSTY_MPM_PM_UNRESTRICTED` and `TRUSTY_MPM_DISABLE_HOOKS` set. An unreadable or malformed payload, or a panic in the guard, denies. Each deny is recorded in the pm-guard denial store. S2 registers the mode in launched sessions' settings; until then nothing invokes it (#8454).
