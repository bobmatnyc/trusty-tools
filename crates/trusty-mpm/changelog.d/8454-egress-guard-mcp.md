Added
- New `tm hook --egress-guard` hook mode denies every Slack, Gmail (`gmail` or `google-mail`), Notion and Google Chat MCP tool, and the mail, chat and message tools of a `gworkspace` or `google_workspace` server, including read, search and list tools. It matches the MCP server name after lowercasing and dropping separators, so `Slack-MCP` and `claude_ai_Slack` are caught. `ReadMcpResourceTool` and `ListMcpResourcesTool` are judged by the server they name, and denied when they name none. It applies to subagents and holds with `TRUSTY_MPM_PM_UNRESTRICTED` and `TRUSTY_MPM_DISABLE_HOOKS` set. An unreadable or malformed payload, or a panic in the guard, denies. Each deny is recorded in the pm-guard denial store. S2 registers the mode in launched sessions' settings; until then nothing invokes it (#8454).
