Security
- `tm hook --pm-guard` limits the `Bash` tool of a `research`, `code-critic`, `code-analyzer`, `security`, `Explore` or `Plan` agent to an allowlist of read commands with literal arguments, and refuses every other command (#8439). Allowed: `git status`/`log`/`diff`/`show`/`grep`/`rev-parse`/`ls-files`/`merge-base`/`ls-remote`, `git branch --list`, `git worktree list`; `cat`, `head`, `tail`, `wc`, `ls`, `grep`, `rg`; `find` without `-exec`/`-delete`/`-fprint`; `sed` with a print-only script; `plutil -p`/`-lint`; `defaults read`; `launchctl print`/`list`; `tmux capture-pane -p`; `cargo metadata`/`tree`; `echo`; `pwd`. A pipe into a reader, `2>&1`, `2>/dev/null`, `if <read>; then <read>; fi`, and a `for` loop over literal words or an absolute or `~/` glob are also allowed. Refused: every other program, including `plutil -extract`, `sed -i`, `git checkout`, `git restore`, `git switch` and `git fetch`; `cp`, `mv`, `rm`, `touch`, `curl` and `python`; redirects, here-documents, `&&`, `;`, `||` and `&`; variables, command substitution, `~` and globs outside that `for` loop; environment prefixes and wrappers; and any byte outside printable ASCII, space, tab and newline. Out of scope: these agents' `Write`/`Edit` tools, the user's own shell aliases and functions, and `cargo tree` updating `Cargo.lock`. Other agents and the PM are not bound.
- The guard's git parser no longer reads the value of an unknown global option (`--shallow-file <path>`) as the subcommand, and knows `--attr-source` takes a value (#8439). The main-checkout destructive-git, commit, worktree-add, worktree-remove, `git apply` and git-output rules now check every word that could be the subcommand, so `git --shallow-file status checkout -- <file>` is refused where `git checkout -- <file>` is.
