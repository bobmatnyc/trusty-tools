Added
- `tm tui`'s projects view shows one Owner -> Project -> Sessions tree in place of the Projects and Sessions panes. The owner comes from each project's repository URL (`(local)` for a path); owner bars and project rows show session counts (total and live) and expand and collapse with Enter or the arrow keys, starting collapsed. Workers are indented under the session that launched them, using the daemon's parent link or, without one, their names; `g` turns the indentation off and on. The selection and the open rows survive a refresh, and a removed session's selection moves to its project (#10476).
- Enter on a session opens a read-only details view (Esc closes it). `f` moves this terminal to the session's existing tmux window (`switch-client`) or iTerm2 tab and never opens a new one; outside tmux and iTerm2 it shows a one-line notice. Kill, resume, decommission and attach act on nothing while an owner or project is selected; all other keys keep their meaning (#10476).
