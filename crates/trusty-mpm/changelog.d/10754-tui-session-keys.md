Added
- `tm tui`'s sessions column acts on a session the way `tm ls` does. Enter opens the selected session: it resumes it if needed and attaches, and the tui comes back afterwards. Right shows or hides the session's details (Enter did this before). `r` opens a rename box with the current name filled in; Enter renames and Esc cancels, and a refused name shows as a notice in the action bar. `R` resumes only (`r` did this before), with the same refusal for a session whose workspace is gone. `n` starts a new session in the selected project and attaches, from either column. The action bar lists the new keys, and `[←] collapse/projects` names both things Left does (Refs [#10754](https://github.com/bobmatnyc/trusty-tools/issues/10754))
