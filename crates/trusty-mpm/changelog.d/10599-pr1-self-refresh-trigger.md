Added
- The Architect's fleet poller now refreshes the Architect's own context with no command typed. Once a cycle, `scripts/fleet_poll_selfrefresh.py` starts `self-clear.sh --live` in the background when the Architect's context reaches the context bar (250k tokens by default), the input box holds no typed text, the Architect is between turns and the Intent Ledger is ready. Any check it cannot answer means no refresh. It waits 30 minutes before trying again and never starts a second refresh while one runs: the refresh holds a lock on `inbox/self-clear.pid` for its whole run, the poller sends the Architect no other keys while it is held, and the lock frees itself when the refresh ends. A `self-clear.sh` started by hand refuses (exit 7) while that lock is held (#10599).
- The seeded `self-clear.sh` accepts `--socket PATH --target PANE` and sends every tmux command to that one server and pane, so the refresh clears the same Architect window the trigger checked. Before every key it sends, it confirms the pane still belongs to the Architect's session, and sends nothing (exit 6) if not. With no `--socket` it uses `TMUX_SOCKET`, the server it runs inside, or tmux's default socket, and refuses (exit 5) when that is not a live socket (#10599).
