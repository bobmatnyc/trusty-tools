Changed
- tm no longer writes `spinnerTipsEnabled`, `spinnerTipsOverride` or the `attribution` commit and PR footer into `<workspace>/.claude/settings.json`. Each launch carries them on its one `--settings` payload instead. A bare `claude` started outside tm in the project no longer gets tm's spinner tips or the trusty-mpm attribution footer from that file. A value you set for any of the three keys in `settings.json` or `settings.local.json` still wins (#12077, #12127).
- At the next launch tm removes, once, the copies of those three keys that earlier releases wrote into `<workspace>/.claude/settings.json`, and only where the whole value equals tm's: `spinnerTipsEnabled: true`, tm's spinner tips list, and the trusty-mpm footer as both `commit` and `pr`. An edited value stays and is logged. If the file cannot be read or rewritten, the cleanup logs the error, writes no done marker so a later launch retries, and the launch leaves out of `--settings` any key the file still holds (#12077).
