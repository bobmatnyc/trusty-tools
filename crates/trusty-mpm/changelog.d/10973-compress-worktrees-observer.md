Fixed

- `tm hook` compresses covered Bash output inside an isolation worktree again. Since #7477 it skipped every call under `.claude/worktrees/`, where delegated agents run, so the `compress` savings rows fell from hundreds a day to tens. There it now rewrites to one simple command, `tm compress --tool "<tool>" -- <command>`, which runs the program, compresses its stdout and exits with the program's own status. The `{ …; printf …; } | tm compress` shape the isolation classifier refused is still never emitted there. The rewrite is skipped when the cwd is unknown, when a `deny` permission rule matches the original command, when the program word is not an executable file (a shell function or alias such as an `rg` function keeps running in the shell), and for heavy builds, which stay leased uncompressed. If reading the program's output fails after it exited 0, `tm compress` exits 1 (#10973).
