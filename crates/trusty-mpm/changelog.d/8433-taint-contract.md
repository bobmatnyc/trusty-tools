Added
- A channel taint contract: one module (`core::channels_taint`) writes, reads and retires the taint file a session gets when it receives an answer through an outbound channel, at `~/.trusty-tools/trusty-mpm/channels/taint/<session_id>.json` (mode 0600, written atomically). An unreadable or malformed file, and a session id that is not a plain id, read as tainted; only a missing file reads untainted. No timer retires a taint. Each taint file records the directory it covers, and ending one managed session never untaints a session id while another tainted session's workspace still overlaps that directory; a taint file that records no directory is never removed by ending a session (#8433).
- The taint directory is a trust anchor: no session, the Architect included, may write, move, truncate or delete a taint file while a taint exists, and a taint directory that does not resolve still protects every directory above it. The trust-anchor floor also reads `truncate` operands as writes (#8433).
