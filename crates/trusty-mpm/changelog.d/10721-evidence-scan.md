Fixed

- The Session Manager delegate's evidence scan no longer accepts failed or empty results as proof (Refs [#10721](https://github.com/bobmatnyc/trusty-tools/issues/10721)). A failed session record is `Failed` even when its pane shows evidence. The latest test summary or failure line decides the run: a later failing summary, compiler error or panic blocks all evidence, and a later passing summary (positive pass count, zero failures) counts as evidence. A write claim must name a written path. A PR URL counts only as the result of a `gh pr` action with no failure line before it: any PR from `gh pr create`, or the PR the task named for `comment`/`edit`/`merge`/`review`/`ready`. The task text echoed into the pane is ignored.
