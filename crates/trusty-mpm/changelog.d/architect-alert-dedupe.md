Fixed
- The Architect's poller no longer re-wakes the Architect every 30 minutes for an unchanged host alert. Swap, load and disk alerts are keyed by kind, severity and value bucket, and re-fire only when the severity or bucket rises, when the alert recurs after two clear cycles, or on a 24-hour reminder. Swap alerts only while swap-in/out is active; leftover swap is logged. Swap is critical only with active swapping and critical OS memory pressure, and disk is critical above 95% (ar-T8a).
- A held Architect gets only urgent alerts (owner answers, a dead, silent or frozen Architect, permission prompts, dialogs, questions, exited sessions, critical swap or disk). The hold is `inbox/hold.json`, written by `datg.py session set --hold` on the Architect's own ledger and by the owner's Away or Sleeping state. Other alerts are logged with a `held` field, and the release sends one `held_digest`. A hold file that cannot be read, or has expired, holds nothing (ar-T8a).
