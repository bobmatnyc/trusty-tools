Fixed
- A channel answer can no longer reach a session whose `SessionStart` never reached the daemon while its path tools stay allowed. On a session's first path tool call, `tm hook --egress-guard` now checks whether a live owner-answer taint mark covers the session's launch directory (`CLAUDE_PROJECT_DIR`) or its current directory. If one does, the guard taints the session for that mark's managed session, so retiring that session removes the taint, and refuses the call. A mark that cannot be read or listed, a taint write that fails, and an unknown launch directory while any mark exists each refuse the call too. Every session at or under a marked workspace is now refused path tools until that managed session ends (#9923, #8433).
