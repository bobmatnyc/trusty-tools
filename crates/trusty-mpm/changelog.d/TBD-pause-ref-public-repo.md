Fixed
- A session pause no longer pushes its snapshot ref to a public repository (#TBD-pause-ref). The `refs/tm/sessions/` push now runs only when `gh api repos/<owner>/<repo>` confirms the push URL's repository is private; a public origin, a non-GitHub origin, or a failed lookup skips the push, keeps the local snapshot, and reports the reason in `ref_error`. On a private origin the pushed snapshot reads `~` for the home directory, and the ref's user segment is a stable hash instead of the gh login or `git config user.name`, so a resume reads only refs written after this change.
