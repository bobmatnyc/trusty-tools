Added
- The Architect's resume digest has a RECONCILE block that checks the handoff file and `local/standing-rules.md` against the Intent Ledger (#10960). It runs on startup, resume, `/clear` and compact, and in `datg.py digest`. A line that cites an expired owner ruling is marked `EXPIRED, not applied`. A line that cites a superseded ruling is marked `SUPERSEDED, not applied` and names the ruling at the end of the `superseded_by` chain. A current owner ruling that the handoff or the standing rules leave out is restored with its quote and cite. A standing-rules line, or a handoff line that claims an owner ruling, with no ledger record is flagged. A superseded ruling is history and is never reported missing. The block emits FLAG lines only: no hook decision and no exit code changes.
- An unreadable handoff, standing-rules file or ledger is said in the block, which then never reports "all reconciled". A corrupt ledger at SessionStart now injects a `ledger unreadable ... NOTHING RECONCILED` line instead of nothing, and `datg.py digest` prints the same line on stdout before its existing exit 2.
