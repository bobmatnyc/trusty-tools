Added
- `tm session archive <id> [--dry-run] [--force] [--json]`, the `session_archive` MCP tool and `POST /api/v1/sessions/managed/{id}/archive` move a session's project directory to `~/.trusty-tools/archive`, created and kept at mode 0700. Each archive entry holds the directory and a `manifest.json` that records the origin path. A same-filesystem move is a rename. Across filesystems the copy must verify byte-for-byte before the source is removed. A manifest that cannot be written undoes the move (#10991).
- A session still running in the directory refuses the archive unless `--force`, which stops it first; an Architect session always refuses. `--dry-run` runs the same checks and prints the plan without changing anything. Session records are kept (#10991).
- A project record carries `archived_at`, and `tm tui` hides an archived project from the MPM pane. A new session for the project clears the state (#10991).
