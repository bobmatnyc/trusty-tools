Fixed
- `tm fleet init` no longer grants the supervisor profile over a directory holding a git repository it never looked at. The preflight scan now walks `node_modules`, `build`, `target` and the other dependency and build trees in full (only `.git` keeps its shallow check), both in the directory and in its private `local/` repository. A directory symlink whose target leaves the directory, or a mount point inside it, now refuses, naming the link or mount; links that stay inside the directory, such as a pnpm `node_modules`, still pass. Skip-listed trees now count against the 16384-directory scan budget, and a tree past it refuses naming the budget and where the scan stopped. The `CLAUDE.md` seed guard and automatic `git init` keep their existing scan (#10457).
