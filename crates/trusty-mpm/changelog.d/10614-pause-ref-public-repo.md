Fixed
- A session pause no longer pushes its snapshot ref to a public repository (#10614). The `refs/tm/sessions/` push now runs only when `gh api --hostname github.com repos/<owner>/<repo>` confirms that EVERY push URL of `origin` is a private repository; a public origin, a non-GitHub push URL, or a failed or timed-out lookup skips the push, keeps the local snapshot, and reports the reason in `ref_error`. A lookup that outlives its bound is killed and reaped. On a private origin the pushed snapshot reads `~` for the home directory, and the ref's user segment is a stable hash instead of the gh login or `git config user.name`. A resume that finds no hashed ref still reads a ref written under the old login-named segment; nothing is written or pushed under that name.
