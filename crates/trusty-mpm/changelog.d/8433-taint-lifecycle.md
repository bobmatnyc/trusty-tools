Added
- `tm hook --egress-guard` denies the path tool calls (`Read`, `Edit`, `MultiEdit`, `Write`, `NotebookEdit`, `Glob`, `Grep`, `Bash`) of a channel-tainted session, and of a call that names no `session_id` (#8433).
- At `SessionStart` the daemon re-applies a tainted managed session's taint to the new Claude session id before it answers, for a stopped managed session in that directory as well as an active one. When it cannot, the `SessionStart` hook call fails, and the hook taints the new id itself so the egress guard still denies. The hook does this only when a tainted managed session's workspace covers the session's directory, and its taint retires with that managed session. A double failure is recorded inside the protected taint directory for `tm doctor` (#8433).
- A deliberate stop or a decommission of a managed session retires its taint files; nothing else removes them. A new `tm doctor` row, `channel_taint`, lists orphaned taint files (a deliberately stopped session's taint among them, which means its retire failed), failed re-applies and double failures, and deletes nothing (#8433).
