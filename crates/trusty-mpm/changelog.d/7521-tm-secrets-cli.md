Added
- `tm secrets` stores project secrets through the trusty-secrets socket, starting the server on first use (#7521). `set KEY [group]` writes the project scope only (the owner scope is set from the console) and reads the value from the clipboard (or stdin with `--value -`, never an argument), refuses an empty clipboard, and confirms with the first 8 characters and the length, or only the length for 8 characters or fewer. `list` prints the key names of the project and owner scopes only. `doctor` reports socket and backend reachability, and exits 1 when the server refuses or the selected backend is unavailable. No verb prints a value.
- `tm secrets remove KEY [group]`, `import <path> [group]` and `copy --from <backend> --to <backend> [KEY...]` (#7521), all in the project scope only. `remove` exits 1 naming a key the project scope does not hold. `import` loads a dotenv file, skips and names `secret://` references, reports a syntax error by line number without its text and stores nothing, and exits 1 naming any key that failed while still importing the rest. `copy` copies the named keys, or every project key, between backends inside the project and exits 1 naming any key not copied. None of them prints a value or a mask.
