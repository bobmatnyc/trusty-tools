Added
- `tm issue board init --owner <login> --repo <owner/repo>` creates a standard GitHub Projects board from nothing, from the embedded `board-v1.yaml` (#10276). It is a dry run unless `--apply`. With `--apply` it refuses when the owner already has a project with the same title, when the repo is already linked to a project, or when `issue-state.yaml` has uncommitted changes. Otherwise it creates the project, replaces the default Status options with the standard ones (minus any `--drop-option`), creates Hold and the four date fields, creates the List, Swimlanes and Roadmap views, links the repo, writes the board README with a manual checklist, and prints the `project:` block to commit.
- `tm issue board apply` reconciles the repo's board to the spec (#10276). It is a dry run unless `--apply`, and a second run makes no change. An option edit sends every existing option with its id, so option ids and item values survive a rename, recolour, reorder or addition. It refuses to remove an option that items still use, naming the option and the item count. `--backfill` adds the repo's open issues, a page at a time, with a pause between writes (`--pace-ms`), resuming from a recorded cursor after a failure. `--status-from-labels` sets each issue's Status from its `status:*` label; without that flag no Status is written.
- `tm issue board check` reports, without writing, the board's drift from the spec, the repo's declared extra fields, information-only items (README, settings the API cannot make, workflow states), open issues not on the board, the token type and scopes from the `X-OAuth-Scopes` header, SSO authorisation from a 403 carrying `X-GitHub-SSO`, and a `default_project` that names another board (#10276). It exits non-zero on drift.
- `tm issue board show` prints the embedded board spec and its version, and `tm issue board add <N>` puts issue N on the board the repo's `project:` block names (#10276). When the token lacks the project scope, `add` posts one `no-project:` comment and exits 0; any other failure (5xx, SSO, a deleted project) exits non-zero with no comment.
- `tm issue board` refuses a tracker other than GitHub, naming it (#10276).
