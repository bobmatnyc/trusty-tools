Added
- `tm doctor` now reports every `CLAUDE.md`, `CLAUDE.local.md` and `.claude/CLAUDE.md` found ABOVE the project root, with each file's size and a token estimate (bytes/4). Claude Code loads memory files from the session cwd up to the filesystem root, so one file at `$HOME` is prepended to every turn of every agent in every project beneath it. The row fails when a file is tm's own seed template with no project content, warns when it carries real content, and passes when every such file is already listed in `claudeMdExcludes`. Session launch emits the same finding as one `WARN`, and `tm doctor --fix --yes` renames a pure seed template aside to `<name>.stale-seed-<YYYYMMDD>` or adds a content-carrying file's path to `claudeMdExcludes` in the project's `.claude/settings.local.json`, leaving the file itself untouched. Seeding a `CLAUDE.md` is now refused outright at the home directory, and at a directory above it that belongs to no git working tree; every directory inside a git project, at any depth, and every first-touch directory still seeds exactly as before. The scan, the launch `WARN`, and `--fix` now resolve a nested subdirectory to the project's real root (the git toplevel, or the nearest `.trusty-mpm`-marked registered directory) before walking, so running `tm doctor` from a crate subdirectory no longer reports — and `--fix` no longer excludes — the project's own root `CLAUDE.md`. Seeding into a marker-less, non-git directory that is itself a WORKSPACE PARENT (a child repository lives beneath it) is refused, naming the child repository found; seeding into any other non-git directory below home now offers to `git init` first, declining by default for every non-interactive caller. `tm sessions instructions --dir <dir>` — the one entry point that can reach this offer with no git-project guard already in front of it — now asks the question for real when stdin is a TTY ("not a git repository; initialise one? [y/N]"), through the same confirm classifier the picker's other yes/no prompts use; every other caller (piped, non-interactive, `session start`'s in-place path, `tm launch`/bare `tm`, which already run their own pre-existing auto-`git init` step before reaching this code at all) keeps the silent-decline default (#7673).
