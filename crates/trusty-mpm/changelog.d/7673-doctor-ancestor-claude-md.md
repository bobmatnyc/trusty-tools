Added
- `tm doctor` now reports every `CLAUDE.md`, `CLAUDE.local.md` and `.claude/CLAUDE.md` found ABOVE the project root, with each file's size and a token estimate (bytes/4). Claude Code loads memory files from the session cwd up to the filesystem root, so one file at `$HOME` is prepended to every turn of every agent in every project beneath it. The row fails when a file is tm's own seed template with no project content, warns when it carries real content, and passes when every such file is already listed in `claudeMdExcludes`. Session launch emits the same finding as one `WARN`, and `tm doctor --fix --yes` renames a pure seed template aside to `<name>.stale-seed-<YYYYMMDD>` or adds a content-carrying file's path to `claudeMdExcludes` in the project's `.claude/settings.local.json`, leaving the file itself untouched. Seeding a `CLAUDE.md` is now refused outright at the home directory, and at a directory above it that belongs to no git working tree; every directory inside a git project, at any depth, and every first-touch directory still seeds exactly as before (#7673).
