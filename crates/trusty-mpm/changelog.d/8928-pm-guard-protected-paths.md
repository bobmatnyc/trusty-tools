Added
- `tm hook --pm-guard` denies a Write, Edit, MultiEdit or NotebookEdit call that targets a Claude Code settings file (`.claude/settings.json`, `.claude/settings.local.json`, the user-tier `settings.json`, `settings.local.json` and `.claude.json`), an `.mcp.json`, a git `config` or anything under a `.git` `hooks` directory, or a path a hook or `statusLine` command runs (#8928 step 7). It also denies a write that gives skill or agent Markdown under `.claude/skills` or `.claude/agents` a new or changed frontmatter `hooks:` key. The rule binds the PM and every subagent; the Architect's main thread is exempt. A settings file that does not parse, a target that does not resolve and an edit whose result cannot be reproduced each deny. The rule is dormant while `[pm_guard] enabled = false`.
