Added
- `tm fleet init` seeds 17 more Architect scripts: the poller helpers (`auto_sleep.py`, `user_state.py`, `morning_brief.py`, `dream_catchup.py`, `il_remind.py`, `il_timeline.py`, `ids36.py`, `dashboard_updates.py`, `dashboard_feed.py`), the hang watchdog `poll-supervise.sh` with `poll-reset-wake.py`, `architect-start.sh`, and the Remote Control and relaunch set (`rc-restore.sh`, `rc-disconnect.sh`, `session-relaunch.sh` with `relaunch_brief.py`, `fleet-restart.sh`). Owner names, the poller session and the transcript directory come from `local/architect.json` or the environment, never from the scripts (#10571).
- `architect-start.sh` and `poll-supervise.sh` read the poll cadence from `poll_interval_s` in `local/architect.json`, the key `fleet-poll.py` reads, and log it; `architect-start.sh` no longer passes `--interval 600`. `poll-supervise.sh` restarts a poller only after twice the interval, at least 600 s, of stale state (#11369).
- `architect_config.py poll-interval|owner-name` prints one config value for a shell script, or exits 2 with the config error (#11369).
