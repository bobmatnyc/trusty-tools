Fixed
- `tm hook --pm-guard` refuses `tmux kill-server` and `tmux kill-session -a` unless the same command gives an explicit `-S` naming a scratch socket: not the socket `$TMUX` names, and not one in the tmux socket directory. `-L`, `TMUX_TMPDIR` and no flag are refused, because an inherited `$TMUX` wins over both. The floor binds every caller under every bypass, reads wrapped, nested and chained forms, the scripts a command runs and inline `python -c`, `perl -e`, `node -e` and `osascript -e` code, and refuses an unreadable command that names a whole-server kill (policy GP-050, #10665). The safe form `env -u TMUX tmux -S <scratch socket> kill-server` passes every floor, inline and from a script: the guard now skips `env`'s option values when it looks for the program, and a moved `$TMUX` no longer hides the server an absolute `-S` names.
