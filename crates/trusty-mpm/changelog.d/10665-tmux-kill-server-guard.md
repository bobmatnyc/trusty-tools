Fixed
- `tm hook --pm-guard` refuses `tmux kill-server` and `tmux kill-session -a` unless they reach a scratch server: an explicit `-S` socket that is not the one `$TMUX` names and not in the tmux socket directory; an `-L` label other than `default` and the label of the `$TMUX` socket (`-L` overrides an inherited `$TMUX`, verified on tmux 3.6b); or `env -u TMUX` / `env -i` running tmux directly with `TMUX_TMPDIR` set to an absolute scratch directory other than `/tmp`. `TMUX_TMPDIR` alone, or no flag, is refused, because an inherited `$TMUX` wins over it. A `kill-session` of a `tm-` session on the default or `$TMUX` server is refused too. A command that names a whole-server kill anywhere but a judged tmux command or the argument of an inert program (`echo`, `printf`, `grep`, `rg`, `sed -n`, `cat`, `git … -m`) is refused, so a script written and run in the same command, `awk`, `ssh` or an alias cannot carry one. The floor binds every caller under every bypass and reads the scripts a command runs; `scripts/sandbox_daemon.sh` passes it (policy GP-050, #10665).
