Security

- Control-plane session routes (`/api/v1/control/sessions/*`) now reject non-loopback callers with 403, mirroring the `/rpc` guard, and `ctl_run_session` validates all three caller-supplied spawn inputs before spawning: `claude_cmd` (only the default `claude` is accepted over HTTP), `prompt_file` (absolute, no `..`, no shell metacharacters, existing file), and `workdir` (absolute, no `..`, existing directory). The tmux backend additionally shell-quotes the interpolated `prompt_file` path at the sink, closing a command-injection hole where a `prompt_file` with shell metacharacters was typed into the pane shell and executed (Refs #6197).
