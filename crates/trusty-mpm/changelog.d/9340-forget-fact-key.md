Added
- `tm memory forget --fact-key <key>` forgets the drawer that holds an ADR-0028 slot now, instead of naming its id. It lists the whole palace through `memory_list` and forgets the one live drawer whose `fact_key` matches, through the same `memory_forget` call as the id form. It exits non-zero with nothing deleted when no live drawer holds the key (an expired occupant is named, for the id form), when several do (every candidate id is named), when the listing may be incomplete, and when the daemon is too old to report `fact_key`. The id and `--fact-key` are mutually exclusive ([#9340](https://github.com/bobmatnyc/trusty-tools/issues/9340))
