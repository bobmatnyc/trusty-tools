Added
- `tm doctor` reports on the trusty-search project map with four read-only rows (#9169). `search_project_no_index` warns when no live index answers for this project. `search_project_duplicate_index` warns when a project still has a live worktree, orphaned or same-root duplicate (remedy `trusty-search project park <id>`). `search_project_two_checkouts` warns when a project has a second live main checkout that no operator pin settles (remedy `trusty-search project pin <id>`). `search_project_map_unreadable` fails when the daemon cannot read `project-map.toml`. The per-project resolves are capped at 64 projects, 3 s each and 15 s in all. A daemon that does not answer, a daemon older than trusty-search 0.60.0, and any project whose resolve fails are reported as "not checked", never as ok.
