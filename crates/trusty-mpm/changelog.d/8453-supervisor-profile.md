Added
- A supervisor instruction profile. A project whose `.trusty-mpm.toml` sets `profile = "supervisor"` launches with the bundled supervisor instructions instead of the PM instructions, the new bundled `trusty-mpm-supervisor` output style, and the Opus tier alias (`opus`, never a pinned model id) as its model. `tm hook --pm-guard` lifts the PM delegation rules for that session without `TRUSTY_MPM_PM_UNRESTRICTED`; the destructive-command, worktree, secret and write-boundary guards still apply. A missing, unreadable, malformed or unknown `profile` value keeps the PM profile. PM sessions are unchanged, and a PM project cannot select the supervisor style. `tm doctor` recognises the new style (#8453).
