# test_fixtures — Core Unit Test Fixtures

This directory holds static fixtures used by `crates/trusty-mpm/src/core/`
unit tests.

## `former-mpm-git-file-tracking.md`

The exact, byte-for-byte content trusty-mpm bundled at
`crates/trusty-mpm/src/assets/skills/mpm-git-file-tracking.md` immediately
before PR #1872 deleted it as part of the mpm-*→tm-* skill rename (commit
`bbd2faf8`, the parent of the deletion commit `2a245e87`):

```bash
git show bbd2faf86a809e62a00ee909aaffda0abb0e8180:crates/trusty-mpm/src/assets/skills/mpm-git-file-tracking.md \
  > crates/trusty-mpm/src/core/test_fixtures/former-mpm-git-file-tracking.md
```

Its sha256 (`8450fa909f729bd8095db3a3705bcb44c91c48f069fcd23f212e144b90612aaf`)
is one of the entries in `stale_skills.rs`'s
`FORMER_TRUSTY_MPM_SKILL_CONTENT_SHA256` frozen table. `stale_skills.rs`'s
`find_stale_mpm_skills_confirms_origin_via_frozen_checksum_fallback` test uses
this fixture to prove the content-checksum fallback in
`is_confirmed_trusty_mpm_origin` actually matches real historical content, not
just a fabricated string engineered to satisfy the test.

**Do not edit this file.** It must stay byte-identical to the historical
commit for the checksum to remain meaningful; if the frozen checksum ever
needs to change, regenerate this fixture from the exact same git ref.
