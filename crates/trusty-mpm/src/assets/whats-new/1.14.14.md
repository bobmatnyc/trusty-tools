# What's new in trusty-mpm 1.14.14

## What's new, from the CLI
`tm whats-new` prints these highlights for the release you have installed.
`tm doctor` names the release once, the first time it runs after an upgrade.
Try: `tm whats-new`

## Configurable config dir
`~/.trusty-mpm` and `~/.trusty-tools` now follow `TRUSTY_MPM_CONFIG_DIR`,
or `config_dir` in `~/.trusty-tools/install.toml`.
A broken `install.toml` makes launches and writers refuse, naming the file.
Try: `tm doctor`

## Architect agents from fleet init
`tm fleet init` writes five Architect agents into the Architect project's
`.claude/agents/`: runner, event-extractor, improver, improvement-curator
and drift-guard. A re-run keeps any agent you edited.
Try: `tm fleet init --no-launch`

## Safer session send
`tm sessions send` refuses when the Claude Code input box already holds text,
so it never appends to a draft, and it waits for a slow paste to commit.
Try: `tm sessions send <session> "hello"`

## Build lease catches empty test runs
`tm build-lease` fails a `cargo test` that ran no test although no filter was
given, and names the target. It exits 65 instead of reporting a pass.
Try: `tm build-lease status`
