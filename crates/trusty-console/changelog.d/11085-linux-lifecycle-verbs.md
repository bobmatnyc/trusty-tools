Added
- Linux only: `trusty-console start`, `stop` and `restart`, on `trusty_common::linux_lifecycle` (#11085). `start` spawns `serve` from the install dir and returns once it serves the console socket. `stop` exits 1 when no console runs. `restart` stops, confirms the stop, then starts, and starts a console that is not running. A console whose socket bind failed is found through the listener its `http_addr` file names, and is signalled only after the lifecycle module confirms it is this console. `start` and `restart` refuse while `TRUSTY_CONSOLE_TOKEN_FILE` is set, because the spawned console would not receive it. macOS is unchanged.
