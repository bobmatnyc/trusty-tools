Added
- `page_snapshot` reads every frame of the leased tab, cross-origin and out-of-process iframes included, as the browser's accessibility tree over the existing `debugger` permission (CDP `Target.setAutoAttach` with flat child sessions); each node carries a frame ref `f<frame>:<node>`, and the reply lists the tabs the leased tab opened (#11362)
- `page_click`, `page_hover`, `page_type`, `page_press`, `page_scroll`, `page_select`, `page_upload`, `page_drag` and `page_screenshot` accept a frame ref; a click adds each out-of-process frame's offset to reach viewport coordinates, a navigated frame answers `DocumentChanged`, a removed one `StaleElement`, and a frame that refuses a script world `FrameScriptBlocked` (#11362)
- With DevTools or another debugger on the tab, `page_snapshot` answers `page_read` with `fallback` and `reason: DebuggerBusy`; Chrome's PDF viewer and a frame with no tree are listed with `refused: PdfViewer` or `refused: FrameUnreachable` (#11362)
