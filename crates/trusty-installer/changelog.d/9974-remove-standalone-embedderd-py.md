Added
- trusty-embedderd-py 0.2.0 is library-only, and trusty-search now ships the `trusty-embedderd-py` launcher binary (#9468). When `tctl install` or `tctl upgrade` falls back to `cargo install trusty-search`, it first reads `<cargo root>/.crates2.json` (`CARGO_INSTALL_ROOT`, else `CARGO_HOME`, else `~/.cargo`). If a standalone `trusty-embedderd-py` package owns that binary, tctl runs `cargo uninstall trusty-embedderd-py --root <root>` before the install, so cargo no longer refuses on the binary's ownership and trusty-search ends up owning all three binaries. With no such record, nothing extra runs; a missing or malformed `.crates2.json` counts as no record (#9974).
- If that uninstall fails, the install stops with an error that names the package and the manual fix, `cargo uninstall trusty-embedderd-py`, instead of running a `cargo install` that would refuse (#9974).
