Added

- `analyze.lsp_diagnostics`, `analyze.lsp_references` and `analyze.lsp_analysed_at` on the analyze socket, with the MCP tools `lsp_diagnostics`, `lsp_references` and `lsp_analysed_at` (DOC-72 §5). Positions are `path` plus zero-based `line` and `column`; every answer carries `document_version` and a `<git head>+<dirty hash>` `snapshot`; a `version` other than the file's current one is refused as `lsp_stale`; diagnostics the server publishes without a version are returned marked `unversioned`; `lsp_analysed_at` blocks until a version is analysed and answers `ready` or `timed_out` with `version_seen`. An optional `parent_event_id` is accepted. Off unless `ANALYZE_LSP=1`; every refusal is error code `-32006` with `data.kind` (`lsp_disabled`, `lsp_file_not_found`, `lsp_outside_workspace`, `lsp_unsupported_language`, `lsp_timeout`, `lsp_hung`, …). A server answering "content modified" (-32801) while it loads is retried with backoff inside the request timeout (Refs #9078).
