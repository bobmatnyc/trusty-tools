Added

- `trusty_analyze::lsp`: an on-demand stdio language-server client and child manager, off unless `ANALYZE_LSP=1` (DOC-72 §2). It spawns `rust-analyzer` once per workspace root in its own process group, frames LSP messages with `Content-Length`, correlates requests with a per-request timeout, versions documents read from disk (`didOpen` at 1, `didChange` only when the content hash changes), and returns typed errors (`lsp_disabled`, `lsp_not_installed`, `lsp_initialize_failed` with the stderr tail, `lsp_timeout`, `lsp_hung`, `lsp_stale`, …). An idle server is killed after 2 minutes (`ANALYZE_LSP_IDLE_SECS`); a crashed or hung one is reported, not respawned in a loop; and no child outlives the daemon's idle exit, SIGTERM, drop or panic. No socket method uses it yet (Refs #9078).
