Fixed

- **`POST /webhooks/github` now fails closed when no webhook secret is configured** (closes [#5173](https://github.com/bobmatnyc/trusty-tools/issues/5173)). With `GITHUB_WEBHOOK_SECRET` unset the handler logged `no webhook secret configured — skipping webhook signature verification` and processed the payload, so any peer that could reach port 7879 could inject arbitrary PR coordinates into the analyze pipeline and make the daemon fetch a diff and post a comment under the daemon's `GITHUB_TOKEN`. An unset or empty secret now returns 401 `webhook secret not configured` before the payload is parsed, matching `trusty-review`'s `handle_github_webhook`. Deployments that relied on the unauthenticated path must set `GITHUB_WEBHOOK_SECRET`; every other endpoint is unaffected and the daemon still starts without it.
