- Roster agents composed by tcode no longer carry the raw `{{TM_SKILLS}}` placeholder, and every skill pointer they carry opens with the agent's own `read_file`. tcode embeds the three skill files `BASE-AGENT.md` points at. The project roster deploy writes them to `<project>/.trusty-code/skill-refs` and points the deployed agents there. An in-process compose (the embedded fallback, or a disk agent carrying the placeholder) points at `~/.trusty-code/skill-refs` without writing anything, and the engineer's `read_file` serves exactly those paths from the embedded copies, in bound and projectless runs. A home directory that is read-only or missing never removes an agent from the roster; with no home the pointer stays unresolved and a warning names the path. Neither directory is a skill-discovery path, so the copies never shadow the embedded skill catalog (#7727).
