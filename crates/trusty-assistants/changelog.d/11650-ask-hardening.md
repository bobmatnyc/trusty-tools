Fixed
- An ask replays only the newest logged turns: at most `[ask] max_replay_turns` (default 20) and `[ask] max_replay_chars` characters (default 48000). Older turns stay in `stores/ask-turns.jsonl` but no longer grow every request until it fails on context length (#11650).
- A corrupt last line in `stores/ask-turns.jsonl` (a torn append, a blank or non-JSON line) no longer blocks every later ask. The ask moves its bytes to `ask-turns.jsonl.corrupt-<time>`, truncates the log to the last good line and logs a warning naming both. A bad line before the last, or an unknown record version, is still a `CorruptTurnLog` error and the file is left alone. Reads and appends take an exclusive lock on the log (#11650).
- The ask cancel flag is per ask. `AskEngine::ask_with_cancel(question, flag)` takes the flag and `AskEngine::ask` uses a fresh one; `AskEngine::with_cancel_flag` and `AskEngine::cancel_flag` are removed. A cancel no longer fails every later ask on a long-lived engine (#11650).
- `okg_search` reads at most 2000 files per search and says when it stopped early. A path it cannot walk, stat or read as UTF-8 is named in the result; with no hits that result is an error, not "no matches". Files skipped for size are counted in a note (#11650).
- An ask spawns only the MCP servers that contribute at least one allowlisted read-only tool. Other configured servers are no longer started on every ask (#11650).
