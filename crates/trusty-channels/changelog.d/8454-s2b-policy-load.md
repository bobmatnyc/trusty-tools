Added

- `policy` gains the route loader's file I/O. `load_effective` reads trusty-mpm's `config.yaml` and each project listed for the consumer's channels, and returns a `LoadReport`; `PolicyLoader` reloads it when the content of a file, a repo's `HEAD` or its default-branch commit changes. A project's `routes.toml` takes effect only when the project dir is the top level of its own git repo, `HEAD` is on the default branch (`origin/HEAD`, else the one of `main`/`master` that exists; a detached `HEAD` is refused) and the bytes read equal the file at that branch's commit, read locally with no fetch; a git step that runs longer than 10 s is killed and refused (`GitTimedOut`). A missing home directory, a missing or symlinked host file or host config directory, a host file whose real path is not `~/.trusty-tools/trusty-mpm/config.yaml` under the real home directory (such as a symlinked `~/.trusty-tools`, checked on every load and reload), a symlinked `projects` entry on any channel, or an oversized host file denies every route; the host and route files are opened without following a symlink or waiting on a FIFO; a symlinked, oversized, malformed, non-UTF-8 or unreviewed project file refuses only that project, each with a named reason. On reload a refused project keeps its last reviewed routes, marked `Stale`; a host fault denies all at once, including one in an entry the consumer does not serve; a reviewed narrowing applies at once; rate-limit windows are kept. A cross-file overlap now denies only the consumer whose channels it touches, a project listed for two channels no longer overlaps itself, and a project-file error no longer repeats a value from the file. gchat's own load gate is unchanged (refs [#8454](https://github.com/bobmatnyc/trusty-tools/issues/8454))
