Added
- New `gchat::api` module: a Google Chat API layer for a Chat app reached over Cloud Pub/Sub. `GchatClient` loads a service-account JSON key from a path (refused unless its mode is exactly 0600, before any network call), mints RS256 JWT-bearer access tokens for the `chat.bot` and `pubsub` scopes and caches them until five minutes before expiry, posts messages with `spaces.messages.create` (thread key sent as `thread.threadKey`, optional `messageReplyOption` and `requestId`; a thread key with no reply option sends `REPLY_MESSAGE_FALLBACK_TO_NEW_THREAD`, because Chat's default ignores the key), and pulls and acknowledges a Pub/Sub subscription. Pulled messages decode into typed Chat `MESSAGE` events; a malformed message is a per-message error that keeps its ackId. No `Debug`, `Display` or error text carries key material or a token. No binary yet (refs [#9448](https://github.com/bobmatnyc/trusty-tools/issues/9448))
