Fixed

- Reloading the Assistant GUI no longer discards the visible conversation. Every persona chat turn was already persisted to a trusty-memory `chat_session` keyed `persona-{agent}`, but nothing read it back, so the chat view started empty on every load. `GET /api/agents/:name/chat-history` now serves that log, bounded to the newest page, and the UI rehydrates from it once the API is healthy. Older turns load on demand from a "Load earlier messages" control, addressed by absolute index so paging back stays correct while new turns arrive. An agent that binds no memory palace, a session that does not exist yet, an unreachable trusty-memory, and a malformed payload each report `available: false` with a reason the UI logs, so a down daemon still leaves a usable chat and a real failure is not silently indistinguishable from an empty history.
