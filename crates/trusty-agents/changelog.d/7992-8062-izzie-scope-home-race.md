Fixed

- Izzie's flat manifest (`.trusty-agents/agents/izzie.toml`) now allows `memory_recall` and `memory_remember`, the two tools its `[tools].scopes` memory grants had no binding for (#7992). The flat file is the `extends`-shadow fallback and the manifest the REPL / Telegram persona-dispatch paths read directly, so it does not inherit the base `assistant` allowlist that #7448 fixed — a remember request on that path answered "no such tool". A new regression test pins every shadowed flat manifest's memory scopes against the tool set `assistant_memory::bind` actually keeps registered.
- `stores::binding::tests::explicit_private_store_root_resolves_to_its_bound_index` now holds `test_env::HOME_LOCK` across both of its `$HOME` reads (#8062). A concurrent `$HOME` swap landing between the test's own `AssistantHome::for_instance` call and the second one inside `binding_for` made the two paths disagree, failing the test with "refusing to feed an index that describes a different tree".
