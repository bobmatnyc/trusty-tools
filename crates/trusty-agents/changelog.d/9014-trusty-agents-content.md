Changed
- `tagent` no longer compiles in its bundled agents or workflow definitions. They are read from content `agents/trusty-agents/{agents,workflows}/` through the resolver `tm` uses: the trusty-tools checkout above the cwd, else the installed content bundle. With no content installed, startup deploys nothing to `~/.trusty-agents/` and reports one error naming `tm content update` (on stderr; in the interactive REPL, whose tracing goes to `repl.log`, printed there directly); `tagent agents deploy` and `tagent agents repair` fail with the same message. A content release that lacks a required file (`ctrl.toml`, `pm.toml`, `assistant/agent.toml`, `assistant/persona.md`, `prescriptive.json`) fails the load naming that file. A content release older than this change does not carry these files: run `tm content update` (#9014).
- A directory-package `persona.md` and an `events/<connector>.md` may start with YAML frontmatter; the prompt, the wake instructions and the persona editor see only the body. The bundled files carry `metadata: {version}` frontmatter (#9014).
- Release order: content-v2.2.2 and a `trusty-code` release carrying `assets::content::resolve_for_process` (#9961; crates.io has 0.7.0) publish before `trusty-agents` (#9014).
