Changed

- The `tagent --api` sidecar's parent-death watchdog now delegates to `trusty_common::parent_death` instead of carrying its own copy of the detection loop. Three behaviours change with the move: the poll runs on a dedicated OS thread every 250 ms rather than a Tokio task every 2 s, so the sidecar releases its port about eight times sooner after the GUI dies; it now raises SIGTERM on itself and only forces the exit if that has not completed within five seconds, where it previously always exited immediately; and it holds that SIGTERM until the sidecar has a handler installed for it, so the raise runs the shutdown path rather than killing the process on the default disposition. It also gained pid-reuse protection — the watched pid is paired with the parent's process start time. Because `--parent-pid` carries a pid alone, that start time is read from the live pid at arm rather than stamped by the GUI; the reparent check, which pid reuse cannot fool, is always armed here and covers that window (#7085).
