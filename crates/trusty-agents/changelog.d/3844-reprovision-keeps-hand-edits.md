Fixed

- Reprovisioning bundled agents no longer overwrites a file the operator hand-edited. Every `cargo install` changes the bundle stamp, and the refresh that followed rewrote any bundled file whose bytes differed from the shipped template — archiving the operator's version to a `.stale.<digest>.bak` nobody was told to look for. `~/.trusty-agents/agents/.bundled-provenance` now records the digest of what the tool itself last wrote at each path, so a divergence it cannot attribute to its own prior deploy is kept, counted, and reported on stderr at startup and by `tagent agents deploy`. A stale copy the tool did write is still refreshed, so a shipped template change reaches an older install as before. `tagent agents repair` still overwrites everything, archiving the current content first (#3844).
