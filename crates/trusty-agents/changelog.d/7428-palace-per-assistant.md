Added
- One trusty-memory palace per assistant, with an opt-in fan-out to other assistants' palaces (#7428). An assistant's palace is its `[[stores]] palace` where one is declared, else its instance id, so an assistant that declares none now recalls and persists instead of reporting no memory; a derived palace is created on first use, and a failed creation reports unavailable memory rather than falling back to any other palace. `[memory] fan_out` in an assistant home's `config.toml` names other assistants whose palaces are also recalled from — one `memory_recall` call per palace, merged and ranked with the own palace winning ties, every drawer tagged with its source palace. Writes still go to the own palace alone. `GET`/`PUT /api/assistants/{id}/memory` reads and writes the setting, and the Knowledge pane shows the resolved palace plus a selector over the other assistants.
