Fixed

- ctrl no longer ships a local `ollama/qwen3:30b` model slug — the bundled `ctrl.toml` and `ctrl/agent.toml` templates now carry `claude-sonnet-4-6`, so re-provisioning cannot point the Concierge at a local daemon that isn't running (refs [#3766](https://github.com/bobmatnyc/trusty-tools/issues/3766))
- the `run_pm_task_with_history` conversational path no longer surfaces a raw `Connection refused` from an unreachable local model as the assistant's reply. It now gates error recovery on the FAILURE (a transport-level failure of a model that resolved to a local adapter) rather than on the `local_inference` preference — previously `local_inference.enabled = false`, the setting meaning "avoid Ollama", was exactly what guaranteed an Ollama transport error was unrecoverable. The `ctrl_turn::dispatch` path carries the same defect and is NOT fixed here (refs [#3766](https://github.com/bobmatnyc/trusty-tools/issues/3766))
- the local-failure fallback now retries against a genuinely distinct remote model instead of re-using the agent's configured model verbatim, which for a locally-configured agent was the same unreachable slug and could never succeed; when no distinct remote model is configured the user gets an actionable message naming the unreachable host and the config key to change (refs [#3766](https://github.com/bobmatnyc/trusty-tools/issues/3766))
