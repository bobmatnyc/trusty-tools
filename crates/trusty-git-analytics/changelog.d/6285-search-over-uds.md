Changed
- `tga audit`'s trusty-search preflight now speaks framed JSON-RPC over the daemon's Unix socket (`search.health`) instead of probing `GET /health` over loopback HTTP. The socket path is derived from `trusty_common::daemon_socket_path("trusty-search")`, the same call the daemon binds, so there is no address to discover and no `http_addr` discovery file for a stale write to contradict. `TRUSTY_SEARCH_SOCKET` pins it explicitly; `SearchGuard::url` is now `SearchGuard::socket`.
- The refusal names the socket rather than a base URL, and points at `TRUSTY_SEARCH_SOCKET` rather than `TRUSTY_DATA_DIR`, so an operator reading it can act on the address the guard actually dialled. A daemon that answers and refuses the health call is still refused — an error frame never reads as a reachable daemon.
