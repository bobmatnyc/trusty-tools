Added
- `search.file.get` socket method: send `{"index_id", "path", "diff"?}` and get one indexed file's `content`, plus its diff against `HEAD` when `diff` is `"head"` (default `"none"`). The file must be one the index's walker admits under its root. A missing file, an excluded file, a path outside the root and a symlink that escapes it all answer the same `file_not_found` error; a `..` segment is refused as invalid params; a sops-encrypted file is refused with `reason: "sops_encrypted"`. Content is capped at 1 MiB and the diff at 256 KiB, each reported by `content_truncated` / `diff.truncated`. Each git run has a 10 s deadline; when git fails or times out, the content is still returned and `diff.status` is `"error"` with `git_failed`, `git_timed_out` or `git_unavailable`, never an empty diff. Socket-only, in the free lane (#9029).
