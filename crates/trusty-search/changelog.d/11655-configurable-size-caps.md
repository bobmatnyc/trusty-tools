Added
- `source_file_max_bytes` and `office_file_max_bytes` set an index's size caps in `.trusty-search.yaml` or per index in `trusty-search.yaml`. Defaults stay 1 MiB for source files and 10 MiB for pdf/docx/pptx/xls/xlsx/xlsm; each cap accepts 1 byte to 256 MiB, and 0 or a larger value fails config loading. The walk, single-file admission, pushed writes, the watcher and office extraction all apply the configured cap, and a file over it is still recorded in `skipped_files` as `exceeds_size_limit`. The caps apply when the index is registered; `search.index.create` / `POST /indexes` take the same two optional fields and refuse an out-of-range value with `400 invalid_size_cap` (#11655).
