Fixed
- Every ingest path now applies the walker's own admission decision: `index_file` (HTTP, socket, MCP), the file watcher, the dropped-event rescan and boot reconcile no longer index a file the reindex walk excludes (`exclude_globs`, `extensions`, include paths, ignore files, skip dirs, size caps). `index_file` on an excluded path answers `403 index_file_excluded` with `indexed: false` instead of `200`, and drops any chunks an earlier write left for it (#8922).
- sops-encrypted files are never indexed, whatever their extension: content carrying a sops encrypted value plus a sops metadata block (YAML `sops:`, JSON `"sops": {`, dotenv `sops_version=`/`sops_mac=`, INI `[sops]`) produces no chunks, and a file that becomes encrypted loses its old plaintext chunks on its next write, reindex or rescan (#8922).
- A file still on disk that the index now excludes is purged by the next non-force reindex and by the dropped-event rescan, instead of being served from the stale index (#8922).
- An exclude glob that does not parse now excludes every path, with an error log, instead of being skipped and indexing what it was written to exclude; a pushed write or boot-reconcile file whose admission the filesystem cannot decide is refused or left untouched, never indexed (#8922).
