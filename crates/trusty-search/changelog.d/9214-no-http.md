Added
- `trusty-search start --no-http` (or `TRUSTY_SEARCH_NO_HTTP=1`) runs the daemon on its Unix RPC socket alone (#9214, ADR-0032). It binds no TCP port, writes no `daemon.port` or `http_addr` file and removes any an earlier run left, registers no address in the shared discovery registry, and `search.health` reports `transport.http_addr: null`. The background tickers still run, `trusty-search stop` still finds the daemon through its lockfile pid, and auto-discovery is skipped, with a log line naming `--no-http`, because it registers projects over HTTP. The HTTP-only routes (`/ui`, `/upgrade`, `/metrics`, `/api/chat/providers`) are unavailable in this mode. Without the flag nothing changes: HTTP binds, a failed bind is still fatal, and the discovery files are written.
