Added
- `GET /indexes/:id/status` (socket `search.index.status`, MCP `index_status`) reports `embed_window`: `{window, truncated, unmeasured}`. An embed pass counts each chunk's tokens, special tokens included, with the tokenizer the embedder truncates with; `truncated` counts chunks longer than the embedder's input window, whose tail the vector does not cover. Each pass logs one WARN per affected file (index, file, chunk count, tokens, window) for at most 8 files, then one summary WARN. `unmeasured` counts chunks whose length could not be counted (no tokenizer, or a tokenizer error), with one WARN naming the cause. `window` is `null` when the embedder reports no window, which is every sidecar embedder today, so nothing is counted for those (#9284). The counters are in memory only and restart at zero with the daemon; chunking, chunk ids, vectors and stored formats are unchanged (#9284).
