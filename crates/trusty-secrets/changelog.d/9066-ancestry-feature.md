Added
- The `ancestry` feature: the process-ancestry walk (`ancestry::has_agent_ancestor`, `ProcessTable`, `OsProcessTable`, `StartTime`) with std, `thiserror` and libc only, so trusty-console judges its HTTP client with the same walk the socket server uses and links no store, keychain or server. `server::ancestry` still resolves to it (#9066).
- The `client` feature: `server::client::OnDemandSecrets` and the fixed error table `server::errors::ErrorKind` without the store, keychain or server code, so the console bridge spawns and calls the socket on demand. `server` includes both new features; its public paths are unchanged (#9066).
