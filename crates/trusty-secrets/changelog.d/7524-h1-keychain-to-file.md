Security
- On a build with a Keychain (macOS), the server writes a value into the plaintext `file` backend only when the untracked machine config sets `secrets.default_backend: file` ([#7524](https://github.com/bobmatnyc/trusty-tools/issues/7524) H1). Before, `secrets.copy` with `to_backend: file` (`tm secrets copy --from keychain --to file`) let any process running as the same user move Keychain values into 0600 files, past the Keychain's access control. A refused `copy` or `set` writes no value file and no index row, leaves one audit denial, and fails with the new `SecretsError::FileBackendNotSelected` (wire kind `file_backend_not_selected`, code -32077), whose text names the machine-config setting. Reads from `file`, deletes from it (including the delete sweep), and every `file` write on a build without a Keychain are unchanged.
