Added
- `Embedder::input_window()`, a provided trait method (default `None`) that reports the longest input an embedder encodes before truncating, in tokens including special tokens. `FastEmbedder` reports 256 (all-MiniLM-L6-v2's sentence-transformers `max_seq_length`, exported as `FASTEMBED_MAX_LENGTH`), `CandleEmbedder` 128, and `MockEmbedder::with_input_window` sets it for tests (#9275).
- `embedder::chunk_text`, which splits text into overlapping, gap-free chunks that each fit an embedder window, counted with the real tokenizer through the new `ChunkTokenizer` (`FastEmbedder::chunk_tokenizer()` loads the cached tokenizer of the model it loaded). Consecutive chunks repeat `CHUNK_OVERLAP_PERCENT` (10%) of the budget. A tokenizer that cannot be loaded is a `ChunkError`, never an estimated split (#9275).
