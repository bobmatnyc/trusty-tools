Changed

- The `monitor-tui` feature now builds against ratatui 0.30 and crossterm 0.29, up from 0.29 and 0.28. ratatui 0.29 pulled in `lru 0.12.5`, which carries RUSTSEC-2026-0002 (`IterMut` violates Stacked Borrows) and RUSTSEC-2026-0253 (use-after-free in `LruCache::pop`); ratatui 0.30 splits into `ratatui-core`/`ratatui-widgets` and takes `lru ^0.18` instead, so the 0.12 line is gone from the workspace graph entirely (#2872). ratatui 0.30 gave the `Backend` trait an associated `Error` type where 0.29 hard-coded `std::io::Error`, so the generic `run_loop` functions behind `monitor::memory_tui` and `monitor::search_tui` gained a `B::Error: Send + Sync + 'static` bound. The crossterm backend both dashboards actually run on keeps `Error = std::io::Error`, so nothing at a call site changes.
