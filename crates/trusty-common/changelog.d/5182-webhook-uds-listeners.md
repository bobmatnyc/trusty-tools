Added
- The receive half of the console→target webhook relay: `webhook_relay::Inbox` (a durable, fsync-before-return delivery store), `webhook_relay::serve` (the `webhook.deliver` listener, which acknowledges only after the inbox has taken ownership and refuses any other method by name), and `webhook_relay::WebhookListener` (the whole body of a supervised child — bind, serve, exit on SIGTERM, unlink). Socket paths for both targets now resolve from `webhook_relay::{review_socket_path, analyze_socket_path, socket_path_for}` instead of a literal in the sender. `uds::bind_singleton_hardened` takes over a socket file no process is answering and refuses one a live owner is serving. The `webhook-relay` feature now implies `uds`.
