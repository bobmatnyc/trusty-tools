Fixed
- A dream cycle no longer re-embeds a palace that has not changed since its last full cycle. The idle loop ran dedup and the recall benchmark on every resident palace every `idle_secs`, and each run raised the memory daemon's RSS by 0.8–1.7 GB. A full cycle that changes nothing now records a fingerprint of the drawer set in `dream_settled.json`; while the drawer set still matches it, later cycles skip dedup, the recall benchmark and semantic consolidation, and still run pruning and compaction. Any add, forget or content edit changes the fingerprint, and a missing or unreadable marker makes the cycle run in full (#9391).
