Fixed

- `search_index`'s index registration now speaks the trusty-search daemon's Unix socket instead of `http://127.0.0.1:7878` (#7237). `ensure_project_indexed*` resolved the legacy `http_addr` discovery file and POSTed `/indexes` at a listener ADR-0032 retired, so every session launch against a project with no index logged `error sending request for url` and then withheld the index id as `NotConfirmed`. The find-or-create is now `search.index.create` with a bare `CreateIndexRequest`, the collision recovery reads `search.indexes.list`, and the follow-up populate is `search.index.status` plus `search.index.reindex`. There is deliberately no HTTP fallback: an absent socket logs one warning naming the path and reports `DaemonUnreachable`, so a stale `http_addr` left by an older daemon cannot resurrect the failure. The per-file incremental `index-file` path is unchanged and still HTTP.
