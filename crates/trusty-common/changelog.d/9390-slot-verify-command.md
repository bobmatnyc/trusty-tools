Added
- `RememberOptions::verify_with`: a Tier C slot write can carry the command that re-reads its fact. It is stored as the KG triple `drawer:<id> verify_with <command>` under the slot write's commit guard, with no drawer-row or palace-format change. A command without a `fact_key`, an empty one, or a secret-shaped one fails the write before anything is stored; a refused slot stores no command. A write that retires a slot occupant closes that drawer's command. A command that fails to record after the drawer commits does not skip the post-commit steps: the deferred embed, L1 snapshot and closet rebuild still run, and the write then returns `VerifyNotStored`, which names the committed drawer. `KnowledgeGraph::verify_with_many` reads the commands for a set of drawers in one transaction, and `verify_with` joins `FUNCTIONAL_PREDICATES` (#9390).
