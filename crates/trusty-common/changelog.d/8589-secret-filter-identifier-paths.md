Fixed

- The memory secret filter (`check_secret`) no longer refuses relative source paths whose file or directory names are long CamelCase identifiers made of letters only, such as `src/main/java/com/example/ReservationForecastAdjustmentServiceImpl.java`. These paths were most of the memories a kuzu-memory import refused. A file name of 20 or more characters that mixes case and carries a digit, such as `OAuth2AuthorizationRequestRedirectFilter.java`, is still refused ([#277](https://github.com/bobmatnyc/trusty-tools/issues/277), [#8589](https://github.com/bobmatnyc/trusty-tools/issues/8589))
- Google Docs, Sheets, Slides and Drive URLs (`https://docs.google.com/spreadsheets/d/<id>`) now store. The document id is admitted only in its URL position on `docs.google.com` or `drive.google.com`, and only at a length Google issues (19, 28, 33 or 44 characters, or an 86-character `2PACX-` published id). A bare id is still refused ([#8589](https://github.com/bobmatnyc/trusty-tools/issues/8589))
