Added
- `linux_lifecycle::stop_pid`, `stop_pid_with`, `restart_pid` and `restart_pid_with` stop or restart a daemon the caller identified by pid, such as a trusty-console whose socket bind failed. The pid is pinned with a pidfd and must be this instance (binary, `liveness_args`, `instance_env`, `instance_path_args`) before any signal; a pid that is gone falls back to the socket path, and a live pid that is not this instance is the new `LifecycleError::NotThisInstance` (#11085).
- `DaemonDescriptor::instance_path_args` declares argv flags, such as `--data-dir`, whose value names the instance's directory. A process that gives such a flag only values naming another path is a sibling and no longer blocks `stop`, `start` or `restart`; a relative or unresolvable value still counts as this instance. Descriptors that leave it empty behave as before (#11085).
