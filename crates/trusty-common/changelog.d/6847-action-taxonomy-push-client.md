Added

- `control_bus::HarnessPayload::Action`, carrying the six-kind `ActionEvent` taxonomy (`Workflow`/`Agent`/`File`/`Tool`/`Session`/`Inference`) and its supporting types (`ActionMeta`, `Actor`, `ObjectRef`, `ObjectType`, `PathRef`, and five phase enums) per DOC-73 §3.2. Additive: an old subscriber matching on `domain` alone skips an `action` frame cleanly.
- `control_bus::PushClient` (behind the `uds` feature, unix only): the buffered producer-side UDS transport to trusty-console's event-bus ingest socket (DOC-73 §4.2). `send` is synchronous and never blocks the producer; it enqueues into a buffer bounded by BOTH a frame count (default capacity 4096) and a cumulative byte budget (default 8 MiB, `DEFAULT_PUSH_BUFFER_BYTES`), dropping the oldest frame on either overflow and counting every drop. `flush` dials console ONCE for the whole drain — not once per frame — writes every buffered frame down that one connection, then half-closes; it stops and re-queues the first failed frame. `ObjectRef.label`, `PathRef.path`, and `PathRef.diff_ref` now carry a doc note that producers must scrub free text through `credentials::scrub_secrets` before setting them, and `EventId`'s module doc notes its UUIDv7 timestamp is redundant with `HarnessEvent.at`.
