Added
- Each finding in the `review_diff` / `review_pr` result and the CLI JSON now carries `quoted_snippet`, the code it quotes from its cited `file` at `line`. The reviewer schema requires it; a reply from a reviewer that omits it takes the first code the finding body quotes (#10782).
- The reviewer schema has a top-level `questions` array for "confirm / check / verify X" notes with no code to quote. The result reports them as `questions`, absent when empty; no gate, grade or verdict reads them (#10782).
- A finding with no quote is withheld before grading and the line-citation gate, under the new reason class `no_quote_pregate`, so `withheld_by_reason` and the withheld headline still count it. An all-withheld review keeps its #9310 outcome (`all_withheld` on APPROVE, `suppressed_reject` otherwise) (#10782).
- The line-citation gate places a finding that carries `quoted_snippet` on that quote alone: the cited line must hold it, or the finding moves to its one occurrence, or is withheld. A quote absent from the file is withheld, and every other snippet the finding quotes must still be in the file (#10782).
