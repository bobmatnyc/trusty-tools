Added

- Hosted repo review skills (#11899 step 2, DOC-93 RS-38): a webhook-triggered review now reads the `[[review.skills]]` entries of the base commit's `.trusty-review.toml` and each `.claude/skills/<name>/SKILL.md` through the Contents API at the pull request's base SHA, in the reviewed repository only, with the same caps, skip kinds, `repo_skills` record and review-body section as `run` and the MCP `review_pr` tool. A 404 is the only "absent" answer: an HTTP error, a timeout, a rate limit or an unresolvable base commit is a named skip (`config_unreadable` for the config, `unreadable` for a skill). A symlink the API follows, a directory and a non-file entry are `unreadable`; the API's reported size is checked against the 8 KiB cap. A fork pull request reads the base config only and requests no skill file.
