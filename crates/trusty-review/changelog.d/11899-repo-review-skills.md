Added

- Repo review skills (#11899, DOC-93): `[[review.skills]]` entries in `.trusty-review.toml` (`name`, optional `apply_to` path globs) name skills at `.claude/skills/<name>/SKILL.md` in the reviewed repository. `run` and the MCP `review_pr` tool read the entries and each skill through git at the pull request's base commit, never the head or the working tree, and append loaded skills after the review template as a fenced block labelled untrusted repository guidance. A fork pull request loads none and the review says so. Each skill is capped at 8 KiB and the total at 24 KiB; a missing, invalid, over-cap, duplicate, non-matching or malformed entry is skipped and named in the review body, never failing the review. The review JSON gains an optional `repo_skills` record with each loaded skill's name and sha256. The hosted webhook path is unchanged. Entries are capped at 32 and each git read at 10 seconds; a skill holding a fence-marker lookalike is skipped; names and reasons render in the review body as inert code spans, capped at 8,000 characters.
