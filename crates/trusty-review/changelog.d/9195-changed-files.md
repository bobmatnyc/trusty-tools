Added
- MCP `review_pr` and `review_diff` accept an optional `changed_files` boolean and `changed_files_budget` integer (bytes), and `run` takes `--changed-files` and `--changed-files-budget <BYTES>`. `changed_files` shows the PR's changed files whole, read through the GitHub Contents API at the PR head SHA, for the reviewer only, as `## Changed files (full text at the PR head)`. Off by default; a review without it is unchanged. The budget defaults to 120,000 bytes and is clamped to 400,000 (the clamp is named in the ledger); 0 reviews the diff only; a budget without the flag does nothing. A mistyped MCP value is an invalid-params error (#9195).
- A file is shown whole or not at all. Over budget, test files drop first, then generated files, then the largest, ties broken by path. Every file left out is named under `Not shown:` in the prompt with a fixed reason (`not UTF-8`, `binary`, `too large`, `read failed`, `over budget`, `over fetch cap`, `deleted`, `sensitive path`, `not reviewed`), and that list is paid for out of the budget first. Paths such as `.env*`, `*.pem`, `*.key`, `id_rsa*`, `*credentials*` and `*secret*` are never read, and credential-shaped text in a shown file is masked. At most 60 files are read, 8 at a time, each with a 10-second timeout (#9195).
- File text is context, not evidence: citations, the verifier and inline comments still use the diff only, and a finding that quotes a line outside the diff is withheld. On the map-reduce path each chunk prompt carries only its own file's text, in that file's first chunk; a file no chunk prompt reviews is named `not reviewed` (#9195).
- The source ledger gains a `changed_files` row after `claude_md` (nine rows), with one item per changed file. A local diff or `review_diff` has no head SHA, so the row is `unavailable` and the review runs (#9195).
- The `*credentials*` and `*secret*` deny rules match any directory in the path, not only the file name, so a file under `k8s/secrets/` or `config/credentials/` is named `sensitive path` and never read (#9195).
