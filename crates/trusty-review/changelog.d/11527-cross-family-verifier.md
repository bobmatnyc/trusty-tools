Changed
- The verifier now defaults to a different model family than the reviewer: Amazon Nova Pro (`us.amazon.nova-pro-v1:0`) on Bedrock and Gemini 2.5 Flash on OpenRouter, replacing Claude Haiku 4.5. The Bedrock default now needs `bedrock:InvokeModel` access to `amazon.nova-pro-v1:0` (through the `us.` cross-region inference profile) in the account and region trusty-review runs in; without it the startup liveness probe falls back to Haiku 4.5 (`us.anthropic.claude-haiku-4-5-20251001-v1:0`) with a warning, and refuses live mode only if Haiku is unavailable too. An explicitly configured verifier model that is denied still refuses live mode. To keep the previous verifier, set `TRUSTY_REVIEW_VERIFIER_MODEL=bedrock/us.anthropic.claude-haiku-4-5-20251001-v1:0`. `--verifier-model`, `TRUSTY_REVIEW_VERIFIER_MODEL` and `[models.verifier]` still override it.
- A warning is logged when the reviewer and verifier resolve to the same model id.
