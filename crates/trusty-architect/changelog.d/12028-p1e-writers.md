Added
- `trusty-architect-state-archive`, `trusty-architect-brief-id` and `trusty-architect-aliases`, Rust ports of the Architect's `state-archive.py`, `brief-id.py` (with its library `brief_ids.py`) and `aliases.py`, in the library module `writers`. Eighty-six recordings of the frozen scripts (19 state-archive, 41 aliases, 26 brief-id) replay clean against them, written files included: `state-archive` rewrites both files in place, archive first; `brief-id assign` rewrites the brief in place and appends one registry row; `aliases add` writes `<table>.tmp` and renames it over the table. A failed read or write exits 1 and never prints a success line (#12028). The binaries take the checkout from the nearest directory at or above the working directory holding `ARCHITECT.md`, as the scripts take it from their own location; run outside every checkout, a command that needs it exits 1 and writes nothing (`state-archive` with `--state` and `--archive`, and `aliases` with `ALIASES_FILE`, need none) (#12073).
- The shared `argparse` parser takes a list of positionals (`nargs` none, `?`, `*` and a subparsers action, with `choices`), keeps every value of a repeated option, and returns unrecognized arguments to the caller; `argparse_sub` adds `add_subparsers` on top of it (#12028).
