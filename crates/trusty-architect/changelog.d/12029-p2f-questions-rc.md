Added
- `questions::rc` ports `questions_rc.py` (Remote Control on the questions session follows the open interactive questions; the `inbox/questions-rc.json` state file) and `questions::start` ports `start-architect-questions.sh` (queue append, prompt or launch, the `relaunch.log` URL line), with the same command-line shapes. The live tmux comes from a fixed directory list, never `PATH`; a failed tmux call or write is exit 1 and runs nothing after it: the state file and `relaunch.log` stay unchanged, and with several ids a failed queue append keeps the ids appended before it. `ARCH_Q_RC_SLEEP=nan` pauses 0 s between URL reads. Twenty-four recordings of the frozen scripts replay clean through `examples/replay_port.rs`, every tmux call on a private socket. (#12029 P2f)
- `questions::start` resolves the default Claude config dir through `install_paths`, where the frozen script always used `$HOME/.trusty-tools/trusty-mpm/claude-config`: `TRUSTY_MPM_CONFIG_DIR` or `install.toml` moves it, and a malformed `install.toml` is exit 1 with no `new-session` and no `relaunch.log` (ids already queued stay queued). `CLAUDE_CONFIG_DIR` still overrides.
