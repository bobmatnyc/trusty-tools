Added
- `dashboard::rpc`: the twelve `mpm.architect.dashboard.*` methods (`get`, `list`, `set`, `update`, `delete`, `batch`, `pruned`, `validate`, `fsck`, `tally`, `footer`, `ids`), one request type per verb that refuses unknown keys, and `DashError::code`: a stale `if_version` exits 1, a refused request 2, an unreadable or locked store 3 ([#10063](https://github.com/bobmatnyc/trusty-tools/issues/10063))
- `dashboard::verbs`: one body per verb over the store a request names (an absolute root; for a write, the prune log outside it), a `set` with no `if_version` on an existing document refused as a conflict, and `render`, which prints each reply as `dashboard-db.py` does ([#10063](https://github.com/bobmatnyc/trusty-tools/issues/10063))
- `fsck` reports a live record whose `goal`, `depends_on` or `links` entry names an id no document holds (LDG-2.2.5) ([#10063](https://github.com/bobmatnyc/trusty-tools/issues/10063))
